# Samsung Unveils Industry-First 400-Layer V10 BV-NAND, Memory Density Up 58% vs V9

TrendForce — August 5, 2026

Samsung showcased its latest memory innovations at Flash Memory Summit (FMS) 2026, presenting breakthroughs across NAND, DRAM, and HBM product lines.

---

## V10 BV-NAND: Industry's First 400+ Layer 3D NAND

Samsung introduced the V10 BV-NAND (Bonded Vertical NAND), the industry's first 400+ layer V-NAND product. Key specifications and milestones:

- **Layer count**: 400+ layers (vs V9's ~300 layers)
- **Storage density**: +58% improvement over V9
- **Manufacturing technology**: Wafer bonding + 3-Stack architecture
- **Production status**: Already in mass production; being supplied to NVIDIA
- **Next milestone**: V11 targeting ~500 layers, currently under development

The V10 BV-NAND achieves its density leap through Samsung's Bonded Vertical NAND architecture, which separates the peripheral circuit layer from the cell array layers and bonds them using wafer-level bonding technology. The 3-Stack configuration stacks multiple cell decks to reach 400+ layers without proportionally increasing manufacturing complexity.

---

## zNAND-O: On-Device AI Storage Hybrid

Samsung unveiled zNAND-O, a novel memory architecture designed for on-device AI workloads that combines:

- DRAM-class access speed
- NAND-class storage capacity and density
- Optimized for large language model inference at the edge

zNAND-O targets the growing need for high-capacity, fast-access storage in smartphones and edge AI devices, where fitting large AI models in limited power and space budgets is critical.

---

## zHBM: 8× HBM5 Performance for AI Accelerators

Samsung revealed the zHBM (zero-latency HBM) concept at FMS 2026, a next-generation 3D memory architecture targeting AI accelerator integration:

- **Performance claim**: 8× HBM5 bandwidth/performance
- **Architecture**: Custom IP integration between memory stack and AI accelerator die
- **Approach**: Direct physical integration of memory and compute logic, eliminating conventional off-package memory bottlenecks
- **Target**: AI training and inference accelerators requiring extreme memory bandwidth

zHBM represents a departure from standard HBM packaging; it integrates memory directly with the accelerator die through custom interconnect IP, enabling unprecedented bandwidth density.

---

## HBM5: 2× HBM4E Performance with HPB Thermal Technology

Samsung presented HBM5 specifications:

- **Performance**: 2× HBM4E performance
- **Thermal innovation**: Heat Path Block (HPB) technology
- **Thermal resistance improvement**: −20% vs HBM4E
- **Target applications**: Next-generation AI training accelerators (post-Blackwell/post-GB200 era)

The HPB (Heat Path Block) technology addresses thermal management challenges in high-density HBM stacks by creating optimized heat dissipation pathways through the stack structure. This is critical as HBM stacks grow taller and power densities increase.

---

## LPDDR5X-PIM: Compute-in-Memory for Edge AI

Samsung also showcased LPDDR5X-PIM (Processing-in-Memory), which integrates AI computation capability directly within DRAM for mobile/edge devices, reducing data movement energy cost.

---

## SK Hynix at FMS 2026: V10 375-Layer 4D NAND

Also at FMS 2026, SK Hynix announced its competing V10 4D NAND product:

- **Layer count**: 375 layers
- **Architecture**: 4D NAND (peripheral under cell)
- **Power efficiency**: 2.5× improvement over previous generation
- **Production timeline**: Mass production for enterprise SSDs (eSSDs) expected in early 2027
- **Market segment**: High-performance enterprise storage

---

## Context: FMS 2026 Memory Technology Showcase

Flash Memory Summit 2026 served as the venue for major memory vendors to preview their roadmap technologies. Samsung's announcements — V10, zNAND-O, zHBM, HBM5, and LPDDR5X-PIM — collectively define its memory architecture direction for the 2027–2029 timeframe, with an emphasis on AI workload optimization at all levels from cloud to edge.
