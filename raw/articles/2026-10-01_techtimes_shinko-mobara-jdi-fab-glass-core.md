# Shinko 取得 JDI 茂原廠作為玻璃芯基板「新核心工廠」

## 關鍵數字（原文直引）

| 項目 | 數值 |
|------|------|
| 標的 | Japan Display Inc.（JDI）**茂原工廠**（千葉縣茂原市 3300 Hayano） |
| 收購價 | **未揭露**；JDI 預計認列**約 514 億日圓（約 3.25 億美元）特別利益** |
| 總用地 | **約 373,000 m²**（約 92 英畝） |
| 無塵室 | **約 179,000 m²** |
| 可用電力 | **超過 100 MW** |
| 分割 | 東側 **140,000 m² 歸 Shinko**；西側 **232,000 m² 轉予 FICT Co., Ltd.** |
| 交割 | **2027 年 3 月底** |
| 投產 | **FY2028** |
| 競標者 | **Micron Technology**、資料中心業者、另有至少一家半導體／資料中心標的方 |
| 技術規格 | Shinko **22 層玻璃基板**，**兩面各 11 層銅佈線** |

用途：**AI 晶片封裝之玻璃芯基板生產**；Shinko 將茂原定位為「先進半導體封裝的新核心工廠」。

## 為何對本 wiki 重要

1. **玻璃芯從研發轉入「建廠＋電力」階段的第一個具體場址數字**。>100 MW 與 179,000 m² 無塵室是本 wiki 首見的玻璃基板產線基礎設施量級。
2. **「22 層 = 兩面各 11 層銅」首次拆解**。此前 wiki 僅記 TrendForce 之「22 層」（2026-08-18，已收錄），未知其為單面或雙面計數。➜ 與 Shinko US20260293748A1（本輪專利，核心腔體內嵌元件）同屬「核心層功能化」路線。
3. **顯示器廠轉半導體封裝廠 = 邊界外擴的第五型態**。前四型態（2026-09-29／30 記載）為玻璃／陶瓷製造業者、載板業者、IDM 向載板取用製程、玻璃廠進入基板層；本件為**面板廠廠房與電力資產**進入先進封裝。玻璃基板偏好大面積方形基板，與面板廠房設備同型，此一資產轉移具結構性意義而非單純財務交易。
4. ⚠ **Micron 競標失利**值得列管：記憶體廠爭取同一座面板廠，動機不明（HBM 後段？玻璃中介層？）。
5. ⚠ FY2028 投產意味 **2027 年內玻璃芯基板不會有來自此廠的量產供給**，與 Ibiden 之 FY2027（ABF）形成兩條不同時程。
