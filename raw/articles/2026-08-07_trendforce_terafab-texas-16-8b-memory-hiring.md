## Key Facts

- **Location**: Grimes County, Texas
- **First phase investment**: $16.8B (per Reuters, Aug 6)
- **Total potential**: up to $119B (May regulatory filing)
- **Scale**: ~100 million square feet; 3,000+ jobs
- **Purpose**: Fully integrated hub — manufacture, package, and test advanced logic and memory chips
- **Customers**: Tesla Optimus humanoid robots, Cybercabs, SpaceX orbital data centers

## Memory Engineering Hiring (DRAM Push)

Tesla posted Memory Process Integration Engineer role at Terafab:
- End-to-end DRAM process integration
- Sub-20nm DRAM node development
- Memory cell optimization
- Emerging memory: MRAM, RRAM, 3D DRAM support
- Collaboration across manufacturing and circuit design

Wccftech: signals Terafab expanding beyond AI logic chips into advanced memory manufacturing, potentially challenging Samsung/SK Hynix/Micron oligopoly.

Musk quote: "the most epic chip-building effort... combining logic, memory, and advanced packaging all under one roof."

## Near-Term Supply Agreements

- Micron "making room for Tesla" (Musk on July earnings call) at "reasonable terms" despite "pretty insane" memory prices
- AI5: split Samsung + TSMC production
- AI6: Samsung (full responsibility)
- AI6.5: TSMC

## Advanced Packaging Significance

Terafab is Intel's listed packaging collaborator (Intel joined TeraFab April 2026 as founding partner for EMIB/Foveros). $16.8B Phase 1 is now confirmed; initial estimate was $55B total (now up to $119B). Terafab signals vertical integration of logic + memory + AP as new strategic paradigm for hyperscale AI.
