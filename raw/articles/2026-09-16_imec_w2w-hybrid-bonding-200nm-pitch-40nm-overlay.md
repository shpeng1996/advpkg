# Imec and EV Group demonstrate wafer-to-wafer hybrid bonding with 200nm interconnect pitch and record high overlay accuracy

## Key numbers

| Item | Value |
|------|-------|
| Cu interconnect pad pitch | **200 nm** |
| Post-bond Cu pad-to-pad overlay vector | **below 40 nm for 100% of dies** across a full 300 mm wafer |
| Pad grid | hexagonal arrangement |
| Designed Cu density | **25%** |
| Wafer size | 300 mm |
| Bonding dielectric | **SiCN** |
| Cu pad recess | controlled to a few nanometres |
| Pre-processed routing | four layers of routable interconnect on each wafer before bonding |

## Process and tooling

CMP step prior to bonding; pre-bond lithography corrections applied; bonding performed on **EVG GEMINI® FB** hybrid/fusion wafer bonding system.

## Electrical results

Described as a "robust and highly yielding" technology; daisy-chain structures with equal pad size tested, with cumulative resistance distributions reported.

## Roadmap

imec and EVG state the intent to push "well below 200nm interconnect pitch" for **logic-to-logic and memory-to-logic** stacking.
