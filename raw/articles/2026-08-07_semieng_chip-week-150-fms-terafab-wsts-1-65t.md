## Memory / FMS Conference (Future of Memory and Storage)

- **Sandisk + SK Hynix** released HBF spec: xPU-HBF host interface, performance expectations, reliability and packaging guidance for HBF die stack
- **Samsung** showed zHBM (HBM stacked directly above AI accelerators), zNAND-O (multiple V-NAND via TSVs), and 400+ layer BV-NAND using wafer bonding
- **Kioxia + Sandisk**: 10th-gen QLC 3D flash, bit density >37 Gb/mm², 4.8 Gb/s interface
- **NEO Semiconductor**: unified AI memory platform — SRAM + high density on-chip + 3D DRAM using 3D NAND manufacturing
- **SK Hynix**: developing 375-layer 4D NAND
- **Marvell**: PCIe 6.0 SSD controller, rack-level memory expansion/pooling, multi-rack optical shared-memory for AI inference

## Capacity

- **SpaceX/Tesla Terafab**: $16.8B first phase, Grimes County TX, ~100M sqft, 3,000 jobs; logic + memory + packaging vertically integrated; Tesla Optimus/Cybercabs + SpaceX orbital data centers
- **CXMT**: reportedly considering second memory plant in Beijing
- **Silicon Box**: will increase advanced packaging (panel-level) capacity **10X** this year

## Financials

- **WSTS**: worldwide semiconductor market H1 2026 = **$702B** (+102% YoY); memory +305%; logic +45%; full-year forecast ~**$1.65T**

## Industry/Policy

- U.S. Dept. of Commerce: canceled/paused some CHIPS R&D awards; GAO says unclear how redirected funding fulfills advanced-packaging R&D requirements Congress mandated
- U.S. 15% duty on polysilicon-derived products, effective Dec. 4, 2026; counters China competition in IC and solar supply chains
- FCC considering blocking imports of Chinese optical transceivers for U.S. data centers
- S. Korea approved rules: governments may cover 50–100% infrastructure costs for semiconductor clusters
- Taiwan investigating 17 Chinese companies for poaching chip talent

## Deals

- **AMD** acquires **Taalas** (Toronto AI-inference silicon startup)
- **NXP** in talks to acquire **Ambarella** (>$3B)
- **Lumilens** raised $900M (co-packaged, near-packaged, pluggable optical interconnects)
- **Palomino Laboratories** (MicroLED optical interconnects) acquired **Vega Links** (AI interconnect)
- **Anthropic** plans custom chip design team (Reuters, Aug 5)

## Notable Research

- **U. Michigan**: memory-centric accelerator using 56 custom chiplets (each ~2GB SRAM) for space telescopes; 3,000W → 51W
- **MIT**: self-assembled molecular contacts (capillary + van der Waals); 1,000+ devices, sub-1nm layers, 96% yield
- **D-Wave**: fast high-fidelity two-qubit entangling gate for quantum error correction

## Imec Metrology Roadmap

Higher-energy e-beam, shorter-wavelength optics, deeper X-rays, multi-e-beam inspection, multi-head AFM, AI denoising, virtual metrology — covering advanced lithography, logic, memory, and packaging.
