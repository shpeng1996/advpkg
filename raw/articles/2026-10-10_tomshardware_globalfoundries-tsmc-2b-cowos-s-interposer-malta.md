# GlobalFoundries 以 US$2B／五年合約為 TSMC 代工 CoWoS-S 矽中介層

## 一手要點

| 項目 | 內容 |
|------|------|
| 合約金額 | **US$2 billion** |
| 期間 | **五年**，並含後續加產能機制 |
| 廠址 | **GlobalFoundries, Malta, New York**（將增設產能） |
| 對象技術 | **CoWoS-S**（明示；非 CoWoS-L） |
| 量產爬坡 | **2028 上半年** |
| 產能／片數 | ⚠ 未揭露 |
| 晶圓尺寸 | ⚠ 未提及 |
| GF 角色 | **manufacturing service（受託代工／subcontractor）**，非 TSMC 之「供應商」；將生產**多個客戶各自的中介層設計** |
| 發言 | Ed Kaste（GF CMOS 事業資深副總）："By providing manufacturing service using GF's trusted U.S. manufacturing footprint" |

## 報導所提之技術涵義

- GF 需把**設計規則、製程與驗證（qualification）對齊 CoWoS 流程**；IP 歸屬方式未明。
- 中介層的設計**逐客戶而異**（chiplet 數、HBM 數、擺放、供電需求）。
- ⚠ 報導明確提出疑問：**大面積中介層需光罩縫合（reticle stitching），GF 能否處理未知**；亦問 GF 是否能做 **CoWoS-L**。
- 可能之美國境內鏈：Arizona 製邏輯晶粒 → New York 中介層 → TSMC 和／或 Amkor 於 Arizona 封裝（**Amkor Peoria 預定 2028 年初投產**）。
- **HBM 仍須自亞洲供應**，直到 Micron 與 SK hynix 的美國 HBM 組裝廠落成（報導預期於本十年內）。
- ⚠ 報導自提之限制：**中介層產出本身不等於成品處理器** —— 仍需足夠的 chip-on-wafer 組裝與測試產能；TSMC 與 Amkor 之 CoWoS 組裝分工未揭露。

## 為何對本 wiki 重要

**這是本 wiki 首見 TSMC 把 CoWoS 關鍵結構件的製造交給另一家晶圓代工廠。** 既載之 CoWoS 供應鏈外擴皆為 OSAT 側（Amkor 承接 EMIB、ASE/SPIL 承接面板），中介層本體一直視為 TSMC 自製。本件把「**中介層是誰做的**」首次變成一個有第二答案的問題，且該答案是一家**競爭對手晶圓廠**。
