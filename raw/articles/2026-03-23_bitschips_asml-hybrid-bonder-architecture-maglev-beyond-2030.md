# Report: ASML inches forward with hybrid bonding

## 各項主張及其歸屬（逐項標註出處）

| 主張 | 歸屬 |
|------|------|
| ASML 已開始「設計混合接合機台的整體架構」（*"designing the overall architecture of a hybrid bonding tool"*） | **The Elec**，引述未具名知情人士（二手、匿名源） |
| ASML 已接洽外部夥伴，包含 **Prodrive Technologies** 與 **VDL ETG**，兩者皆被描述為**磁浮晶圓載台（maglev wafer stage）**關鍵技術供應商 | **The Elec** |
| 磁浮晶圓載台對混合接合的精度與速度為必要條件 | **本文作者之推論框架**，非具名來源 |
| ASML 已開始探索 3D 整合機會，**包含混合接合**；至 **2025-11** 仍處 R&D 階段；**對營收的顯著影響預期在「well beyond 2030」** | ⭐ **ASML CEO Christophe Fouquet 本人**，於較早一次對 Bits&Chips 的訪談（一手、具名高層） |
| **XT260**（2025-10 推出）為 ASML 在 3D 整合的第一步 | 本文文字 + ASML 提供之照片 |

## 官方確認狀態 / Official confirmation

- ⚠⚠ **ASML 並未確認混合接合機台之報導，且「declined to comment on the report」。**
- Fouquet 的發言描述的是**探索（exploration）**，而非一個產品計畫（product program）。
