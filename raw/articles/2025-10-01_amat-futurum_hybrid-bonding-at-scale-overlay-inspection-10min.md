## 關鍵量化值 / Key Specs

| 項目 | 數值 |
|------|------|
| 微凸塊微縮受限點 | **~10–20 µm pitch** |
| 細間距混合接合 | **<10 µm** 互連 |
| Besi 混合接合機對準精度 | **~100 nm** |
| 能效 | 混合接合下 **<0.05 pJ/bit** |
| HBM 堆疊 | **16-hi 及以上**（HBM4／HBM4E／HBM5） |
| **疊對檢測週期時間** | **自 1–2 小時降至 ~10 分鐘**（自動化 OVL 檢測） |
| Kinex 機台配置 | **1–2 台（R&D）／2–4 台（早期低量）／最多 6 台（高量）** |
| 潔淨環境 | **Class-1 mini-environment** |

## 時程展望（⚠ 分析師口徑，非 AMAT 宣告）

- **2027–2029**：逐步進入 chiplet 式 CPU／GPU／XPU，並有 **HBM 試產計畫**，可能落在 **HBM4E 16-hi 或 HBM5**。
- **十年末**：混合接合可能成為高容量 HBM、邏輯—記憶體混合件與**共封裝光學**的主流。
- AMAT 自身對 Kinex 之表述為 "upcoming"，並稱已示範 16-hi 或更高 DRAM 堆疊之接合；**AMAT 未給具體量產日期**。
