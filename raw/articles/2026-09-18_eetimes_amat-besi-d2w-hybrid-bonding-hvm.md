# Applied Materials, BESI Push Die-to-Wafer Hybrid Bonding Toward High-Volume Manufacturing

> ⭐ 本篇為 wiki 長期未結案空缺「設備商 D2W 對準路線圖」的**直接答案來源**。原空缺假設業界目標為 0.5 µm (3σ)；本文顯示實際已達 **100 nm (3σ)**，即比原假設嚴格 5 倍。

## 對位與放置精度 / Alignment & placement accuracy
- 目前量產要求：**100 nm 對準精度 @ 3σ**（die placement）
- 下一世代系統（**2026 年推出**）：目標 **50 nm 或更佳**
- 後續路線圖：**低於 25 nm**

## 產能 / Throughput
- 現行 Kinex 系統量產中：**1,600 die placements / 小時**
- 最高可達 **2,000 placements / 小時**（視製程而定）

## 封裝與 I/O 微縮 / Package & I/O scaling
- 未來 AI 加速器封裝：尺寸大 **9×**、矽面積增加 **600×**
- 單一模組將含 **超過 400 顆 die**
- 目標 I/O 密度：**每平方毫米上看 100 萬個 I/O**

## 製程整合與時程 / Process integration
- **佇列時間（queue time）**：混合接合把表面劣化的等待窗口從 **約 13 小時壓到數分鐘**（約 **10×** 改善）
- 現況：「已有產品高量生產兩到三年」
- 下一代平台推出：**2026**

## 機台 / Tools
- **Kinex**（Applied Materials 與 Besi 的共同平台）
- 可擴充架構：最多可整合 **六個 bonder 模組**
- 單片晶圓整合流程，消除批次處理延遲

## 效能增益 / Performance
- 相對微凸塊方案，於特定架構上有 **10×** 效率增益
- 併帶降低熱阻、降低功耗、縮短延遲、縮小面積
