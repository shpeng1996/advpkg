# Chiplet Summit 2026：UCIe 主席談 UCIe 3.0 路線圖

## 關鍵內容 / Key content
- **資料率提高至 64 GT/s**，瞄準 AI/HPC 與 on-package memory 頻寬。
- 設計哲學為 **"wider, not faster"**（唯一的直接引語），據此得到**較低的每位元功耗**。
- 新增**連續傳輸（continuous transmission）協議映射**。
- **擴充 sideband 與可管理性（manageability）能力**。
- **向後相容**於前代。
- **UCIe-3D**（以混合接合做垂直 chiplet）列在 **UCIe 2.x** 之下，**不在 3.0**。
