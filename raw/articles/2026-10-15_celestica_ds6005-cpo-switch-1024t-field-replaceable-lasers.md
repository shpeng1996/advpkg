# Celestica DS6005：102.4 Tbps CPO 交換器，外部雷射模組可現場更換（OCP 2026）

> 一手新聞稿，2026-10-12 08:00 EDT；展出於 **OCP Global Summit 2026（2026-10-12 至 15，San Jose）C2 攤位**。

## 規格（新聞稿原文）
| 項目 | 內容 |
|------|------|
| 交換容量 | **"Up to 102.4Tbps"** |
| 埠配置 | **64 × 1.6TbE（102.4T 容量）** |
| 交換 ASIC | **Broadcom Tomahawk 6 – Davisson** |
| 光引擎 | **整合於交換 ASIC 封裝上（CPO）**，取消前面板可插拔光模組；⚠ 新聞稿**未點名光引擎供應商或規格** |
| 雷射 | **"field-replaceable external laser modules"（可現場更換之外部雷射模組）** |
| 形factor／散熱 | **1.5OU、OCP ORv3 機架、全液冷**；稱可「提升溫度穩定性與可靠度，並提高整體機櫃密度」 |
| 軟體 | SONiC，另稱具 **"CPO-aware software management"** |
| 功耗／延遲 | 僅稱「大幅降低」，**無任何數字** |
| 供貨 | **未給出貨或正式供應日期** |

## 為何重要 / Why this matters
1. ⭐⭐ **「外部雷射模組可現場更換」是本 wiki 首見把 CPO 最大可靠度疑慮（雷射壽命）寫進產品層的處置方式**——既載 CPO 討論多停在「雷射外置以降低熱」，此處進一步主張**可維修性**。
2. ⭐⭐ **CPO 的系統側落地證據再加一例**：繼 NVIDIA Quantum-X／Spectrum-X 之後，ODM（Celestica）亦推出以 **Tomahawk 6 – Davisson** 為核心的整機；而 TH6-Davisson 的光引擎係基於 **TSMC COUPE**（⚠ 此關聯見於二手報導，**本新聞稿未述**，故不得引為一手佐證）。
3. ⭐ **全液冷 1.5OU** ⇒ CPO 不只改變封裝，也改變機構與散熱規格。
4. ⚠⚠ **整篇無任何功耗、延遲、距離（reach）數字**，與既載「CPO 的 pJ/bit 缺口屬領域級未解」一致——連產品新聞稿都不給。
