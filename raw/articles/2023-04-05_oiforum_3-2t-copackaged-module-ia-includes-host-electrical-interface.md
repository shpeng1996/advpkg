# OIF 3.2T Co-Packaged Module Implementation Agreement（第一方新聞稿）

> ⚠ **本篇為 2023-04-05 之舊稿，係「刻意收錄」**：用於結清 2026-10-21 所立空缺
> 「電性—光學介面的標準歸屬無人認領」。該空缺之前提（OCI／XPO／Open CPO/CPX 三個 MSA 皆不管電光介面）
> 並未檢查 **OIF** 這一支。

## 文件 / Document

**OIF-Co-Packaging-3.2T-Module-01.0**（Implementation Agreement, IA）。

## 範圍 / Scope — **含主機電性介面**

| 面向 | 內容 |
|------|------|
| 光介面 | **8 × 400 Gb/s**，FR4 與 DR4 兩種連接選項 |
| **主機電性介面** | **32 × CEI-112G-XSR**；向下相容模式 **32 × CEI-56G-XSR** |
| 電性規格 | 在範圍內 |
| 光機械規格 | opto-mechanical module specifications，在範圍內 |
| 控制與管理 | 以既有 **OIF CMIS** 規範之增補實現 |
| 總速率 | **3.2 Tb/s** 聚合；可供 **51.2 Tb/s** 交換器使用 |
| 邊緣頻寬密度 | **約 140 G/mm** |
| 型態 | 光模組**或**被動銅纜組件（passive copper cable assembly） |
| 電通道速率 | **100G 電通道**，向下相容 50G |
| 功耗 | **未提及** |
