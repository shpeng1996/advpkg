# 3D-nanoprinted vertical coupler using hybrid lithography for optical redistribution applications

**Venue**：Optics Letters｜**DOI** 10.1364/ol.599054｜**2026-05-27**｜被引 0
⚠ **OpenAlex `institutions` 欄為空**（作者 Zuyuan He 為上海交通大學知名光電學者，但本輪**不逕自補填**，依規範（38））。

## Abstract（OpenAlex inverted index 還原）

展示用於**光學重分佈（optical redistribution）**的高分子**垂直耦合器**。元件以**混合微影製程**製造：以 **UV 微影**做平面**光學重分佈層（ORDL）**，以**雙光子聚合（TPP）**做垂直耦合微鏡。藉由核心與包覆層之間的**高折射率對比**，實現**全固態全內反射（TIR）鏡，免除複雜金屬化或空氣腔**。為確保可製造性，耦合器設計中加入**支撐結構**。理論預測耦合效率為**無支撐 89.4%／有支撐 81.6%**。實測在 **1310 nm 之耦合損耗約 3.3 dB**。

## 關鍵量化數據

| 項目 | 數值 |
|------|------|
| 耦合效率（理論） | **89.4%（無支撐）／81.6%（有支撐）** |
| 耦合損耗（實測 @1310 nm） | **~3.3 dB** |
| 製程 | UV 微影（ORDL）＋ 雙光子聚合（垂直微鏡） |
| 鏡面型態 | **全固態 TIR**（無金屬化、無空氣腔） |
