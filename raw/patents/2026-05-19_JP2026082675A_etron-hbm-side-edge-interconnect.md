# HBM 堆疊之側邊互連 / HBM stack with side edge interconnect（Etron × ND Hi Tech Lab）

## 英文標題
HIGH BANDWIDTH MEMORY STACK WITH SIDE EDGE INTERCONNECT AND 3D IC STRUCTURE HAVING THE SAME

## 摘要 / Abstract（OPS 原文）
To provide a high bandwidth memory stack with side edge interconnects and a 3D IC structure with the same. SOLUTION: The semiconductor wafer 31 is a 3DIC structure in which edge pad semiconductor dies 10a and 10b are formed, wherein the boundary between adjacent edge pad semiconductor dies 10a and 10b is defined by a scribe line region SL, and each edge pad semiconductor die includes a memory die 1031a or 1031b and a redistribution layer (RDL) 15a or 15b disposed over the respective memory die. The memory die further includes a signal pad 12a or 12b and a seal ring 13a or 13b in each of the memory dies.

## 為何對本 wiki 重要 / Why this matters
**Etron 於 2026-05 公開之本件專利顯示**，其 HBM 堆疊路線將訊號出口自晶粒**正面垂直貫穿（TSV）改置於晶粒側緣（side edge）**：各記憶體晶粒上方配置 RDL，訊號墊與密封環（seal ring）位於晶粒內，相鄰「邊緣墊晶粒」之界線由**切割道區（scribe line region）**定義。此觸及 [[technologies/hbm4]]、[[technologies/tsv]] 與 [[entities/etron]]：若側邊互連成立，HBM 的堆疊層數將不再由 TSV 製程與晶粒薄化能力單獨限制，而與**切割道寬度與切單品質**耦合。
