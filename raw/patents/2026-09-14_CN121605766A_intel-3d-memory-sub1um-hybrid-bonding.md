# THREE-DIMENSIONAL MEMORY ARCHITECTURE WITH HYBRID BONDING

**Publication Number**: CN121605766A
**Family ID**: 96174196
**Applicant**: Intel Corp
**Published**: 2026-03-03

## Abstract (from EPO OPS)

A three-dimensional (3D) memory architecture and its fabrication method utilizing hybrid bonding are presented. The method and apparatus employ ultra-high density (defined herein as sub-1-micrometer pitch) hybrid bonding for memory die stacking.

## IPC/CPC Classes
- H10B (Semiconductor memories)
- H10W (Integrated circuits with heterojunctions)

## Wiki Significance

Intel's 2026-03 patent discloses a 3D memory architecture with sub-1 µm hybrid bonding pitch—far beyond current production capability (TSMC SoIC at ~9 µm, leading research at ~1 µm). This is a forward-looking signal that Intel is actively pursuing ultra-high-density memory stacking to compete with SK Hynix HBM4 on bandwidth and to enable future Memory-on-Logic integration.
