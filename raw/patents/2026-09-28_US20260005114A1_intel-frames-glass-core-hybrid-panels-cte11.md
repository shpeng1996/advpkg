# FRAMES FOR GLASS CORE HYBRID PANELS（Intel）

## 摘要重點（原文譯述）
玻璃核心由一層玻璃構成，其平面區域由若干與該平面大致正交的邊緣圍成，玻璃層中至少一個 TGV **以導電材料實質填滿**。**框（frame）之熱膨脹係數可依框材料之選擇與框材料中銅的百分比加以操縱**；**框的 CTE 低於 11**。框可圍住**一整片面板、子面板或晶圓**，並可含有一個或多個腔體以容納各自的玻璃核心。

## 請求項揭示的設計自由度
- 自由度不是玻璃本身，而是**圍在玻璃外側的框**
- 調節手段：**框材料的選擇 + 框材料中的銅含量百分比**（兩個可連續調節的變數）
- 一個框可容納**多個玻璃核心**（腔體式）→ 適用於面板級的批量搬運

## 為何對 wiki 重要 ★
1. ⭐⭐⭐ **這是「玻璃在機械上不是單一材料」的第四個層級，且是第一個把調節手段放在玻璃「之外」的。** 既有三層級為①用途分級（LPKF）②同一供應商產品線分歧（AGC ER-Y1 vs EN-A1）③單片內部梯度（Intel US20260182414A1 之 CTE 梯度核心）。本件為 **④框（載體）層級的 CTE 調節**——玻璃不動，改動它的邊界條件。
2. ⭐⭐⭐ **本件帶有量化值（CTE < 11）。** 2026-09-27 的 log 記載「專利軌訊號以定性為主連續第七輪成立」；本輪該連續紀錄**中斷**。⚠ 但請求項只給上界，未給下界與量測方法，且未標明溫度區間。
3. ⭐⭐ **「hybrid panel」一詞本身值得追蹤**——暗示面板上同時存在玻璃核心與非玻璃區域，與 wiki 既有「面板全玻璃 vs 全有機」的二分不同。
4. ⭐⭐ 直接支持 **`wiki/technologies/glass-carrier.md` 建頁**（已列為 2026-09-27 的「下輪必辦」）：框與載體是同一問題族。

⚠ **本件為專利，屬前瞻訊號而非已出貨能力。** Intel 玻璃核心商業化目標約 2030（二手來源）。「CTE < 11」為請求項界定用語，非產品規格。
