# PACKAGE STRUCTURE (LOGIC + MEMORY OVER INTERPOSER)

**Publication Number**: CN224007096U
**Family ID**: 96347795
**Applicant**: Taiwan Semiconductor Mfg Co Ltd
**Published**: 2026-03-17

## Abstract (from EPO OPS)

A package structure is provided. The package structure includes a first die formed over the interposer, the first die including a first logic device; a first memory device formed over the first logic device. The structure combines logic and memory stacking over an interposer substrate.

## IPC/CPC Classes
- H10B (Semiconductor memories)
- H10D (Discretes devices)
