# SEMICONDUCTOR PACKAGE INCLUDING INTERPOSER HAVING GLASS CORE LAYER

**Publication**: US20260144093A1 ｜ **Family**: 99804083 ｜ **Published**: 2026-05-21
**Applicant**: Samsung Electronics ｜ **Inventor**: Yang Hyunjoon

## 摘要 / Abstract (English, from OPS biblio)

> A semiconductor package ... comprises: a package substrate; an interposer structure on the package substrate; and semiconductor chips on the interposer structure and electrically connected to the package substrate through the interposer structure, wherein the interposer structure comprises: a glass core layer; first through-electrodes penetrating the glass core layer; bridge structures on the first through-electrodes; bridge connection bumps between the bridge structures and the first through-electrodes; and bridge mold layers between the bridge structures and the glass core layer, and covering side surfaces of the bridge connection bumps, wherein each of the bridge structures comprises a base substrate and bridge through-electrodes penetrating the base substrate and vertically overlapping the bridge connection bumps.

## 關鍵要件 / Key elements

| 元件 | 位置與作用 |
|------|-----------|
| 玻璃核心層 | 中介層的核心 |
| 第一貫穿電極 | 貫穿玻璃核心層（TGV） |
| **橋結構** | **置於第一貫穿電極「之上」**（不是埋入玻璃核心內） |
| 橋連接凸塊 | 介於橋結構與第一貫穿電極之間 |
| **橋模封層** | 介於橋結構與玻璃核心層之間，並**包覆橋連接凸塊側面** |
| 橋貫穿電極 | 貫穿橋的基底基板，且**與橋連接凸塊垂直重疊** |

## 為何對本 wiki 重要 / Why this matters

- ⭐⭐⭐ **「橋要埋進什麼材料裡」自 Intel 的內部分歧擴大為跨公司的分歧軸，且 Samsung 給出第五種、也是唯一「不埋」的答案。** Intel 四種幾何（玻璃腔體內／玻璃貼片上／與玻璃中介層疊成組件後埋入核心層／有機層腔體內）全部是**埋入**；珠海天成（CN121311056A）是**埋入矽轉接板**。**Samsung 本件把橋放在玻璃核心的 TGV 之上、以模封層固定，而非開腔埋入。** ➜ **本 wiki 應記述：此軸的答案至少已有六種，且「埋 / 不埋」是比「埋進什麼」更上位的分歧。**
- ⭐⭐ **玻璃核心 + 橋 + 模封的組合為 Samsung 首見**，且橋本身仍有貫穿電極（橋是**有源/有孔**的，非單純佈線片）。這與 Samsung 的 I-Cube / LSB 路線可能相關 ——`overview.md` 既列「缺技術頁：Samsung X-Cube / I-Cube / LSB」，本件為該頁的建頁材料再增一筆。
- ⭐ 本件的模封層作用（**包覆橋連接凸塊側面**）與 2026-07-31 ASE CN224583751U「橋接晶片組裝模封」在同一方向：**以模封而非開腔來固定橋**。➜ 「模封式橋接」自 ASE 單一來源擴為**兩家**。
- ⚠ 專利訊號，非已出貨能力。全篇**無量化值**：無 TGV 尺寸、無 pitch、無層數、無良率。
