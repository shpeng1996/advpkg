# SK hynix 考慮採用 Intel Foundry 生產 HBM4E Base Die

## 核心主張 / Key Claims
- **SK hynix 評估 Intel Foundry 作為 HBM4E base die 供應商**（Herald Business 報導；SK hynix 官方表示「部分報導不實，難以確認細節」）。主因：TSMC HBM4 base die 成本為 SK hynix 自身 core die（1b 製程）的 3–4 倍，HBM4E 時代差距預計擴大。
- **SK hynix HBM 路線圖 base die 分析**：HBM3E 自製 → HBM4 委外 TSMC 12nm-class → HBM4E 評估 Intel Foundry 分散。
- **三家記憶體廠 base die 策略對比**：Samsung 在 HBM4 使用自研 4nm base die；Micron 的 HBM4/HBM4E logic die 預計均委外 TSMC。
- **Intel Foundry 潛在受益**：若 SK hynix 確認，Samsung/Micron 也可能跟進評估；HBM base die 成為 Intel Foundry Services 重要新業務來源。
- **LTA 成本轉嫁困難**：HBM 高比例長期協議（LTA）制約了成本轉嫁彈性，促使 SK hynix 尋求降低 base die 成本。

## 關鍵數據 / Key Data Points
| 指標 | 數值 |
|------|------|
| TSMC HBM4 base die 成本 vs SK hynix core die | 3–4× 更高 |
| SK hynix HBM4 base die 製程（TSMC） | 12nm-class |
| Samsung HBM4 base die 製程（自製） | 4nm in-house |
| SK hynix America HBM 設計團隊規模 | 50–260K（NewsPim 估計） |

## 新增知識 / New Knowledge Added
- **HBM base die 供應鏈格局首次系統性揭示**：HBM3E 時代 base die 自製 → HBM4 時代委外 TSMC → HBM4E 時代可能多元化（含 Intel Foundry）。
- **HBM base die 成本首次量化**：TSMC 比 SK hynix 自製貴 3–4 倍——這個數字解釋了為什麼 SK hynix Q76% 毛利率下仍有成本優化動機。
- **Intel Foundry 新潛在客戶類別**：從晶片/封裝代工 → 延伸至 HBM base die 代工；若成功，可能重塑 HBM 供應鏈生態。
