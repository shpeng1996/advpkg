# TSMC Patent US20260090444A1 — LSI Top-Via Barrier / Cladding

## 核心主張 / Key Claims（專利訊號）

- **失效模式明確指認**：LSI（local silicon interposer）的 top via 會與**製程膠帶殘留物或其他雜質**發生化學反應，導致**金屬原子遷移與 wire growth**（銅鬚／短路），造成長期可靠度問題。
- 解法為多層阻障／包覆（cladding）結構，材料組合包含 **SiOCH, SiO_x, SiON, SiN_x, CuO_x, Ta, Ti, TaN, TiN, Mo, MoN, TaC, TiC, TaCN, TiCN**。
- 製程流程：cladding 沉積 → 圖案化 → 濕蝕刻 → 等向／非等向乾蝕刻 → flowable／spin-coat 介電沉積 → CMP。

## 新增知識 / New Knowledge Added

LSI 是 **CoWoS-L** 的核心元件（功能對應 Intel EMIB 的嵌入式矽橋）。wiki 先前僅記錄 CoWoS-L 的**產能與尺寸路線圖**，未記錄其失效模式。本專利提供第一筆具體的 LSI 可靠度工程資料。

封裝尺寸放大（2029 年 >14× 光罩）意味 LSI 數量倍增，此類缺陷的累積機率同步放大——可靠度工程是 CoWoS-L 尺寸擴張的隱性限制條件。
