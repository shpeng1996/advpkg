# JCET：以微波剝離載板

## 核心主張 / Key Claims

1. 黏著劑塗層配方：**聚碳酸亞丙酯（PPC）+ 石墨粉 + 光酸或熱酸產生劑**。
2. 以該塗層把晶圓貼附於載板，在貼附狀態下完成**背面處理**（薄化/TSV 露出等）。
3. **對黏著劑塗層施加微波能量**完成剝離。

## 關鍵數據 / Key Data Points

無任何量化數據（剝離時間、溫度、殘膠、良率、尺寸皆未揭露）。家族 ID `101273744`；IPC H10P72/70；公開日 2026-09-15。

## 新增知識 / New Knowledge Added

1. **微波作為封裝製程的能量投遞方式，本季第二次出現。** 2026-09-16 收錄的 POSTECH 微波退火 Cu-Cu 接合（基板 150 °C / 3 分鐘）與本件的共同邏輯相同——**把能量選擇性沉積在目標界面，而非加熱整個基板**。從「一篇論文」擴展為「論文＋產業界專利，分屬接合與**解**接合兩個製程」，使微波由單點觀察升格為**一條可追蹤的技術路線**。
2. **配方透露機制**：石墨粉為微波吸收體（selective heating）、PPC 為已知可低溫解聚的犧牲高分子、酸產生劑提供觸發。組合意味剝離是**化學解聚**而非熱軟化或雷射燒蝕——與現行主流的雷射解接合（LDB）屬**不同技術家族**。
3. **與 AMAT「薄化至 1/25 厚度」（同日收錄）互補**：載板剝離是薄化流程的最後一步，也是翹曲與破片風險最高的一步。設備商與 OSAT 從兩端各自出手，指向同一個限制。
