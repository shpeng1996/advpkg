# OpenAI Jalapeño AI 推理晶片首發；三星供 HBM4 / OpenAI Debuts Jalapeño AI Inference Chip; Samsung Reportedly Supplies HBM4

## 核心主張 / Key Claims

- OpenAI 首款自研推理晶片 Jalapeño 正式發布，採 TSMC 3nm 製程，整合 6 枚 HBM4 堆疊（216 GiB、15.4 TB/s）。
- 三星傳聞為 Jalapeño 的 HBM4 供應商（有別於 SK Hynix 主供 NVIDIA）——這是 HBM4 客戶多元化的重要信號。
- Broadcom 為 ASIC 合作夥伴；若 OpenAI 依 10GW 部署協議規模出貨，HBM4 市場供應壓力將進一步加劇。
- TSMC 3nm + HBM4 封裝競爭需求確認：OpenAI 進入與 NVIDIA Blackwell/Rubin 相同的晶圓+HBM+先進封裝資源競爭。
- 第二代晶片即將 tape-out，第三代已在研發，顯示 OpenAI 加速自研晶片路線。

## 關鍵數據 / Key Data Points

| 指標 | 數值 |
|------|------|
| 製程 | TSMC 3nm |
| HBM4 堆疊數 | 6 stacks |
| 記憶體容量 | 216 GiB |
| 記憶體頻寬 | 15.4 TB/s |
| 功耗額定 | 700W（持續 ≤550W） |
| 吞吐量優勢 | 1.5×–1.9× vs NVIDIA GB200/GB300（每瓦） |
| 延遲優勢 | 1.7×–3.6× 較低端對端延遲 |
| HBM4 供應商 | 三星（傳聞） |
| ASIC 夥伴 | Broadcom |

## 新增知識 / New Knowledge Added

- **三星 HBM4 客戶多元化正式確認**：NVIDIA 主要依賴 SK Hynix，而 OpenAI Jalapeño 傳聞採用三星 HBM4——這是首次明確報導三星 HBM4 進入大型 AI 推理晶片的量產供應鏈。
- **HBM4 需求新來源**：OpenAI 此前非 HBM 主要買家，Jalapeño 使其首次成為先進封裝（TSMC 3nm + HBM4）競爭者，直接搶佔 2027 年 HBM4 產能配額。

## 矛盾或修正 / Contradictions / Corrections
