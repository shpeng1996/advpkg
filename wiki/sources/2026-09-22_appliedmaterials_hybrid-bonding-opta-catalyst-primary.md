# AMAT 官方混合接合頁（一手複核）

2026-09-21 的 log 將「AMAT 混合接合 CMP 市占」列為最高優先，並新設作業規則：**凡「某公司的某產品做某製程」之敘述，一律以官網產品頁複核**。本輪對 AMAT 執行該規則。

## 核心主張 / Key Claims
1. AMAT 官方為混合接合具名七項產品，涵蓋沉積、電鍍、蝕刻、**CMP** 與**表面製備**五個製程段。
2. **Opta** 與 **Catalyst** 被官方明列為 CMP（平坦化）平台。
3. **Insepra™ SiCN** 被官方明列為「混合接合表面製備」專屬產品。
4. 官方自陳合作：**EVG（W2W）、Besi（D2W）**。
5. 官方技術挑戰表述：「達成無缺陷的銅對銅接合，且晶粒對晶粒對準誤差幾近於零，同時成本更低」。

## 關鍵數據 / Key Data Points
| 製程段 | AMAT 具名產品 |
|--------|----------------|
| 介電沉積 | Producer Invia CVD |
| 金屬沉積 | Endura / Ventura PVD |
| 電鍍 | Nokota ECD |
| **CMP** | **Opta、Catalyst** |
| 蝕刻 | Centris / Sym3-Y |
| **表面製備** | **Insepra™ SiCN** |

⚠ 全頁**無任何市占數字、無 pitch 數值、無製程控制數值、無日期**。

## 矛盾或修正 / Contradictions / Corrections
- ✅ **部分結清**：2026-09-21 對 SemiconductorX 的查證只否證了「Lam SABRE 3D = 混合接合 CMP」，當時**AMAT 自己是否真有混合接合 CMP 產品並未獲一手確認**。本頁確認了產品層事實。
- ❌ **未結清**：「AMAT 混合接合 CMP 市占 100%」仍無任何官方或統計佐證。**「有產品」與「獨占」須分開記錄，後者維持待證，且不得作為其他推論（如「持股 Besi 9% ＝ 沿限制鏈縱向布局」）的前提。**

## 新增知識 / New Knowledge Added
1. ⭐⭐ **2026-09-21 新設的官網複核規則首次用於正向確認**，而非只用於攔錯。規則的效力因此擴及兩個方向。
2. ⭐ **Insepra™ SiCN 使 SiCN 自「材料選擇」升格為可具名的商用製程平台**，與本 wiki 已跨三源確認的 SiCN RMS 0.10–0.2 nm 在供應端連上。
3. ⭐ AMAT 官方把挑戰列為三項並列：**無缺陷（潔淨度）／對準誤差近零（設備）／成本更低（良率經濟）**。與本 wiki 2026-09-19 的限制鏈三層**同構但排序未給**，且**AMAT 不提表面平坦度**——⚠ 一家把 CMP 列入產品線的公司在公開頁面不把平坦度列為挑戰，可有兩種讀法（已解決／不願強調），本 wiki 不裁定。
