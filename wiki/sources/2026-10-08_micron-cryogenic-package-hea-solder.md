# US20260283054A1：低溫環境用半導體封裝組成

⚠ **專利為前瞻訊號**；行文須為「Micron 於 2026-09 公開之專利顯示…」。

## 核心主張 / Key Claims

1. **基板含金屬核心**，其強度規格定義在**低溫門檻以下**之溫度區間。
2. 每顆銲球為**高熵合金（HEA）核心 ＋ 外包銦（In）摻雜銲錫合金鍍層**之複合結構。
3. 記憶體系統（控制器 ＋ 一枚或多枚記憶體晶粒）耦接於該基板；電路板以該等銲球與基板耦接。

## 關鍵數據 / Key Data Points

| 項目 | 內容 |
|------|------|
| 環境 | **低溫（cryogenic）**，門檻**數值未給** |
| 基板 | **金屬核心**，低溫下之強度為請求項限定事項 |
| 銲球結構 | **HEA 核心 ＋ In 摻雜銲錫鍍層** |
| 量化值 | ⚠ **全篇無**（無溫度門檻、無 HEA 組成、無摻銦比例、無強度值） |
| 發明人署地 | 兩位均署台灣（⚠ 未載廠址，不得推論） |

## 新增知識 / New Knowledge Added

- ⭐⭐⭐ **本 wiki 首見「低溫」成為封裝的設計條件。** 既載溫度軸全部朝高溫（TDP、冷板、兩相冷卻、本輪 Advantest 100 W/cm² 測試熱介面）⇒ **溫度自單向的「要散掉多少」變成一條雙向的規格區間。**
- ⭐⭐ **「核心 ＋ 鍍層」之複合銲球為本 wiki 首見之銲球內部結構分層**（既載銲點條目皆視銲球為單一材料）；**高熵合金作為銲球核心**亦為首見材料類別。
- ⭐⭐ **請求項的驗收項是「低溫下的強度」與「摻銦鍍層」而非幾何** ⇒ 延續既載觀察（Absolics 以製程潔淨度與微結構對稱性入請求項）：**排他權的標的正從幾何移向材料狀態與環境條件。**

## 矛盾或修正 / Contradictions

- ⚠ 無與既載條目直接矛盾者。
- ⚠ **目標產品線未載**（量子運算低溫記憶體？車用？航太？）⇒ **新空缺**；追蹤方式：後續 Micron 專利是否出現溫度門檻數值或應用場景。
- ⚠ 與同輪論文軌 HUST「Cu/Ta 介面熱阻隨溫度非單調」同向，**兩者皆顯示溫度相依性本身是設計變數**，但**一為低溫強度、一為高溫介面熱傳，不得互相援引數值（且本件無數值）**。
