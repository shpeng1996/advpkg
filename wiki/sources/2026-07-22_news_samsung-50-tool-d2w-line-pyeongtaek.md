# Samsung 平澤 P5：約 50 台 D2W 混合接合機

## 核心主張 / Key Claims
1. 約 **50 台 D2W 混合接合機**，設於**平澤 P5 廠**。
2. **首選供應商 Besi**（協商中）；備選 **Semes**、**Hanwha Semitech**。
3. **Besi 單價約 ₩60 億／台（≈US$4.6M）**。
4. **機台安裝 2026 年底開始；大規模商業量產目標 2030。**
5. 應用：次世代 HBM 與先進邏輯，聚焦**整合 logic die 的 custom HBM**。
6. **Samsung 要求機台設計變更，延宕交期協議。**

## 關鍵數據 / Key Data Points
| 項目 | 值 |
|------|----|
| 機台數 | **~50 台** |
| 單價 | **₩60 億（US$4.6M）** |
| **機台總額（推算）** | **≈₩3,000 億（US$2.3B）** |
| 安裝起點 / 量產 | 2026 年底 / **2030** |
| 對照：Hanmi 混合接合廠房投資 | ₩1,000 億（Class 100） |
| 對照：TheElec 2026-04-28 機台報價 | ₩40–50 億 |

## 新增知識 / New Knowledge Added
1. ⭐⭐⭐ **本 wiki 首次取得混合接合機的單價與產線規模，可估算資本門檻。** 50 × ₩60 億 ≈ **₩3,000 億僅機台**，對照 Hanmi 的**廠房 ₩1,000 億** ➜ **機台與廠房是一個數量級的差距**，本 wiki 此前只記得到廠房側。
2. ⭐⭐⭐ **設備側的三個獨立時間點彼此收斂於 2029–2030**：Hanmi 量產採用 **~2029**、Samsung 產線大規模量產 **2030**、SK hynix 稱 HB 延後至 **HBM5**。➜ **「HBM4E（2027 年底）導入混合接合」的說法缺乏設備側佐證**，本 wiki 應據此調整該預期的信心水準（不刪除，加註）。
3. ⭐⭐ **首見採購方反向驅動機台規格**：「Samsung 要求設計變更」。值得追蹤變更內容——若涉及對準或吞吐，將是本 wiki 目前最直接的「量產方認為機台還差什麼」的訊號。
4. **設備價格跨來源一致**：₩40–50 億（TheElec 2026-04-28）vs ₩60 億（本篇）➜ 同量級。
