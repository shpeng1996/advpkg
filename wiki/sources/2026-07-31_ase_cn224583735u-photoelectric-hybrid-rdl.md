# ASE：光電混合重佈線結構（CN224583735U）

**公開號** CN224583735U（實用新型）｜**專利家族** 100681519｜**公開日** 2026-07-31｜**申請人** 日月光 ASE

## 核心主張 / Key Claims

1. RDL 層中**光焊墊與電焊墊並置**；光焊墊上方疊導光材料，導光材料上方的**頂部導電材料兼作光波導的反射界面**。
2. 宣稱效益：縮短光電互連距離、提高訊號傳輸效率、以重佈線結構提供更多 I/O、有利產品微型化。

## 關鍵數據 / Key Data Points

無量化數據（實用新型摘要不含性能數字）。結構特徵如下：

| 元素 | 位置 |
|------|------|
| 光焊墊 / 電焊墊 | 電子元件上，並置 |
| 導光材料 | 光焊墊上方 |
| 頂部導電材料 | 導光材料上方，兼作反射界面 |

## 新增知識 / New Knowledge Added

- wiki 的 CPO 頁把 ASE 定位為**組裝夥伴**（JCET、ASE 等 OSAT 擴 CPO 產能），從未記載 ASE 持有**光學 RDL 結構本身**的 IP。這是該頁的新維度。
- 本案的經濟邏輯值得記錄：**重用既有頂部金屬層作為波導反射面 ⇒ 光層不增加額外光罩層**。這是 OSAT 式的成本論證，與 TSMC COUPE 路線（光柵耦合器 + 微透鏡，CN122260581A，2026-09-14 收錄）的效能論證形成清楚對比——**同一屆封裝 IP 競賽中，代工廠與封測廠對 CPO 的切入點不同層**。

## 矛盾或修正 / Contradictions / Corrections

無矛盾。**重要限定**：本案為**實用新型（utility model）**，中國實用新型僅作形式審查，不做實質審查。因此本案是**布局訊號**，不構成已驗證製程的證據。wiki 引用時必須保留此限定。
