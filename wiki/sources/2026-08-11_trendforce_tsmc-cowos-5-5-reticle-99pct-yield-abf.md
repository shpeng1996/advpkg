# TrendForce：TSMC 5.5× CoWoS 良率達 99%；ABF 基板成 AI 供應鏈新瓶頸

**來源**：TrendForce | **日期**：2026-08-11 | **場合**：TSMC VP Jun He（先進封裝技術暨服務副總）於 2026 OCP APAC Summit 演講

## 核心主張 / Key Claims

1. TSMC 5.5-reticle CoWoS 已量產，多客戶一致良率 **>98%**，部分達 **99%**——業界最高公開量化良率
2. CoWoS 路線圖再確認：2028 年 **14× 光罩**（~10 大計算 die + 20 HBM stacks）→ 2029 年 **>14×**
3. SoIC 混合接合間距：6µm（2025 量產）→ **4.5µm（2029）**；A14-to-A14 SoIC 2029 年量產（vs N2-on-N2 提供 1.8× I/O 密度）
4. AI 供應鏈雙重瓶頸確認：**記憶體** + **ABF 基板**（後者為新提出瓶頸點）
5. TSMC CoWoS 開發週期已從 **~2 年/代縮短至 1 年**（平行供應商開發機制）

## 關鍵數據 / Key Data Points

| 指標 | 數值 |
|------|------|
| CoWoS 5.5× 量產良率 | 98–99% |
| CoWoS 路線圖 2028 | 14× reticle，~10 compute dies + 20 HBM stacks |
| CoWoS 路線圖 2029 | >14× reticle |
| SoIC 間距 2025 | 6µm（量產） |
| SoIC 間距 2029 | 4.5µm（目標） |
| SoIC 密度增益 | 50× 更高互連密度 |
| SoIC 能效增益 | 5× 更高能效 |
| A14-to-A14 SoIC I/O 密度增益 | 1.8× vs N2-on-N2 SoIC |
| TSMC 先進封裝設施數 | 10 座 |
| 每年 CoWoS 產能增長率 | ~2× (近 3 年) |
| CoWoS 開發週期縮短 | 2 年/代 → 1 年（縮短 ~3 季） |
| 量產前驗證規範公布時程 | 量產前 1 年 |
| 供應商並行開發導入時程 | 量產前 6 季（18 個月） |
