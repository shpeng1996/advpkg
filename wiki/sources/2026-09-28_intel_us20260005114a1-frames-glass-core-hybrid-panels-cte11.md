# FRAMES FOR GLASS CORE HYBRID PANELS（Intel，US20260005114A1，family 98367295）

## 核心主張 / Key Claims
1. 調節對象**不是玻璃本身，而是圍在玻璃外側的框（frame）**。
2. **框的 CTE 低於 11**，且可由**框材料的選擇**與**框材料中銅的百分比**兩個連續變數操縱。
3. 框可圍住**面板、子面板或晶圓**，並可含**多個腔體**以容納各自的玻璃核心。
4. 玻璃層中至少一個 TGV **以導電材料實質填滿**。

## 關鍵數據 / Key Data Points
- **CTE < 11**（單位未於摘要標明，推定 ppm/°C；⚠ 未給溫度區間與量測方法）
- 調節手段：框材料 + **銅百分比**
- 適用尺度：面板 / 子面板 / 晶圓

## 新增知識 / New Knowledge Added
- ⭐⭐⭐ **「玻璃在機械上不是單一材料」取得第四個層級，且是第一個把調節手段放在玻璃之外的。**

| 層級 | 證據 | 日期 |
|------|------|------|
| ① 用途分級 | LPKF：中介層 CTE≈3/<400 µm vs 核心 ≈7/>800 µm | 2026-09-26 |
| ② 同一供應商產品線分歧 | AGC：ER-Y1 3.5 ppm/88 GPa vs EN-A1 5.8 ppm/75 GPa | 2026-09-27 |
| ③ 單片內部梯度 | Intel US20260182414A1 CTE 梯度核心 | 2026-09-27 |
| ④ **框／載體層級（玻璃不動，改動邊界條件）** | **本件 Intel US20260005114A1，CTE <11** | **2026-09-28** |

- ⭐⭐⭐ **2026-09-27 記載之「專利軌訊號以定性為主，連續第七輪成立」本輪中斷**——本件帶有 CTE <11 的量化界定。⚠ 但僅為請求項上界，非產品規格。
- ⭐⭐ **「hybrid panel」一詞暗示面板上同時存在玻璃核心與非玻璃區域**，與 wiki 既有「全玻璃 vs 全有機」二分不同 ➜ **新空缺：hybrid panel 的非玻璃區域是什麼材料、占比多少？**
- ⭐⭐ 與同申請人同日公開的 US20260005126A1（側壁高分子塗層）**構成「玻璃外圍」的兩注互補布局**（框＝機械與 CTE；塗層＝斷裂起始點）。

## 矛盾或修正 / Contradictions / Corrections
- 無直接矛盾。但 **`glass-substrate.md` 的「玻璃 CTE 3–10 ppm/°C 可調」記載須加註**：該區間指玻璃本體，**框的 CTE（<11）是另一個獨立的設計變數，不可混用。**
