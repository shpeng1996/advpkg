# China's Chip Tool Push: AMEC Expands 3D Memory Equipment; Wellrun Targets Key Metrology Gap

## 核心主張 / Key Claims

- **AMEC Primo XD-RIE™**：為先進 3D 記憶體製造設計，高深寬比 70:1~90:1，採超高頻 RF 優化蝕刻選擇性——定位攻 NAND 高層數製程。
- **AMEC Prefima Unicore™ AM**：自研 12 吋 ALD 鉬沉積系統，用於超高堆疊 3D 結構字線填充，高層數 NAND 關鍵設備。
- **Leadmicro**：CVD 設備已進入量產，覆蓋邏輯、**先進封裝**、DRAM、3D NAND 四大應用——先進封裝設備本土化訊號。
- **Wellrun CD-SEM**：14nm R&D / 22nm HVM 12 吋 CD-SEM，已在中國成熟製程線部署——打破 CD-SEM 幾乎完全依賴 KLA（Applied Materials）局面；已與 CR Micro 簽署戰略合作。
- **中國設備本土化加速**：CSEAC 2026（第 14 屆）展現 AMEC、Naura、Piotech、Leadmicro、Wellrun 五大廠新品，半年內連續兩次（SEMICON China 3 月 + CSEAC 9 月）大規模發布。

## 關鍵數據 / Key Data Points

| 項目 | 數值 |
|------|------|
| AMEC XD-RIE 深寬比 | 70:1 ~ 90:1 |
| QuaStar® ON 單機晶圓通量 | 16 片/批次 |
| Wellrun CD-SEM 節點覆蓋 | 22nm HVM + 14nm R&D |
| Wellrun CD-SEM 晶圓規格 | 12 吋 |

## 新增知識 / New Knowledge Added

- Leadmicro CVD 量產覆蓋「先進封裝」應用——過去 wiki 未記錄中國先進封裝設備供應商 Leadmicro，此為首次出現。
- AMEC 鉬 ALD（Prefima Unicore™ AM）為 3D NAND 字線高層數製程新武器，強化中國 NAND 本土化路徑。
- Wellrun CD-SEM 已部署，CD-SEM 本土化率開始從「幾乎為零」改善——對地緣政治封鎖評估有重要意義。
