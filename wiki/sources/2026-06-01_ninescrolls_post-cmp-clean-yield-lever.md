# 混合接合表面製備鏈：CMP 後清洗被指為關鍵

## 核心主張 / Key Claims
1. 表面製備是**五段鏈**：CMP → CMP 後清洗 → 介電面電漿活化 → 銅面製備（氧化物與 queue time）→ 量測驗證。
2. ⭐⭐⭐ **「CMP 後清洗是繼 CMP 本身之後最大的單一良率槓桿。」**
3. 銅氧化物成長**大致呈對數**，可操作變數為 **queue time**（數十分鐘至數小時，製程相依）。
4. 電漿活化的要求是**低離子能量 + 全晶圓均勻**，而非高能量。

## 關鍵數據 / Key Data Points
| 項目 | 數值 |
|------|------|
| 介電層粗糙度 | 次奈米 RMS，約 **< 0.5 nm** |
| 銅凹陷 | 低於介電面**數個奈米**；**容許窗口常僅約 2 nm 寬** |
| 顆粒 | **1 µm 顆粒 → 數百微米寬的空洞** |
| Queue time | 數十分鐘 – 數小時（無絕對上限） |

## 矛盾或修正 / Contradictions / Corrections
⚠ **與本 wiki 2026-09-19 的限制鏈排序不一致。** 既有排序為 ①表面平坦度（~0.2 nm）> ②die 翹曲（<100 nm）> ③機台對準（100 nm）。本件主張緊接 CMP 之後的是**清洗**。本件**未附數據支持該排序**，故列為**待證的排序修正候選**，既有排序不予改寫。

## 新增知識 / New Knowledge Added
1. ⭐⭐ **「潔淨度」首次取得放大倍率量級**：1 µm → 數百 µm，即 **10²–10³ 倍**。此前本 wiki 的潔淨度記錄全為形容詞。
2. ⭐⭐ **列管空缺「Cu 氧化相門檻」的實務形式被指認為「時間窗」而非「溫度門檻」。** 這比 2026-09-21 的修正（「接合當下表面還剩多少氧化物」）更進一步，給出可操作變數：**queue time**。
3. ⭐ **銅凹陷容許窗口「僅約 2 nm 寬」** 與本輪論文軌的「dishing 控制 3–5 nm」（[[sources/2026-03-27_jsamd_cu-cu-bonding-review-dishing-3-5nm]]）數量級一致，且與 Intel Basim 的「需求 1–5 nm」相容。三源在**窗口寬度**上收斂。
