# Amkor：金屬結構直接貼合晶粒背面，再經 TIM 接 lid（專利訊號）

## 核心主張 / Key Claims

1. 模組由多顆元件＋**只圍在元件「側面」的第一包封物**構成。
2. 金屬結構接於模組背對基板的一側，並**直接耦接各元件的背面**。
3. TIM 接於金屬結構，lid 再接於 TIM。
4. ⇒ 散熱路徑為「**晶粒背面 → 金屬結構 → TIM → lid**」，**封膠被排除在熱路徑之外**。

- ⭐ 既載橫向論述「**某個結構位被整體取消**」（改良型 vs 取消型）在**熱路徑**上的落點：被取消的不是結構件，而是**封膠在熱路徑中的位置**。
- ⭐ 與既載 Amkor CEO McCann「預判兩相冷卻為下一散熱轉型」同屬 Amkor 散熱側布局，但本件仍在**傳導**而非兩相 ⇒ **Amkor 的排他權布局落後其公開論述一個世代**（符合既載「論文／排他權是落後指標」的方向，但此處是公開發言領先排他權）。
