# Intel Patent CN121605766A — 3D Memory Architecture Sub-1 µm Hybrid Bonding

## 核心主張 / Key Claims (Patent Signal)

- Intel 於 2026-03-03 公開之中國專利揭示：基於混合接合的三維記憶體架構，接觸間距達 sub-1 µm（超高密度）
- Fabrication method for 3D DRAM/memory using ultra-high-density (sub-1 µm pitch) hybrid bonding
- Positions Intel's memory integration research well beyond current production capability

| Item | Value |

## 新增知識 / New Knowledge Added

- Intel's sub-1 µm 3D memory patent is a forward-looking research signal, not yet a production roadmap; nevertheless it reveals Intel is targeting the same sub-1 µm regime as imec's joint research
- Suggests Intel may be positioning for a Memory-on-Logic architecture (logic die + memory in same package at sub-µm pitch) that bypasses the traditional HBM interposer approach
