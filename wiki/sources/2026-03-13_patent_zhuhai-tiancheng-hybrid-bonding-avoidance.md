# CN121666157A：以熱壓鍵合繞開混合接合

## 核心主張 / Key Claims
1. InP 晶片貼裝於預製基板並模封 → 於晶片側邊開設**縱橫比 ≤ 10 的盲孔**、填充電鍍銅形成「模封銅端」→ 與 TSV 晶片露銅端**熱壓鍵合**。
2. ⭐⭐⭐ 自述效果：**「避免了對前道混合鍵合設備與超高潔淨環境的依賴」**。
3. 另述效果：降低成本、降低熱損傷風險、緩和應力集中；以模封材料**緩衝 CTE 失配應力**。

## 關鍵數據 / Key Data Points
| 項目 | 值 |
|------|----|
| 模封盲孔縱橫比 | **≤ 10** |
| 目標晶片 | **InP（磷化銦）** → 指向光電／CPO 異質整合 |
| ⚠ 電性、熱阻、pitch | **未揭露** |

## 矛盾或修正 / Contradictions / Corrections
⚠ 申請人為中國中型業者，其商業判斷**不等於產業共識**；本件不可讀為「混合接合的成本劣勢已獲產業確認」。

## 新增知識 / New Knowledge Added
1. ⭐⭐⭐ **本 wiki 第一件把「規避混合接合」寫成明示技術效果的專利。** 既有專利軌紀錄多為在混合接合內部做改良（Adeia 的 CMP 停止層、上海大學的檸檬酸表面處理、Absolics 的微結構請求項）。本件反過來以**放棄混合接合**為價值主張。➜ 「潔淨度／設備門檻是成本項」自本 wiki 的推論升格為**有申請人以排他權下注的商業判斷**。
2. ⭐⭐ **與本輪新聞軌的 NineScrolls 互為表裡**：一邊量化潔淨度失控的代價（1 µm 顆粒 → 數百 µm 空洞），一邊有業者選擇繞開該代價。**同一輪內取得一個瓶頸的「代價量級」與「規避行為」兩種證據，在本 wiki 屬首次。**
3. ⭐ **刻意把 AR 壓在 ≤ 10** 是以放寬幾何換製程寬容度，與「面板圖案化粗快／細慢分工」屬同一類設計選擇。➜ 可歸納為**新的橫向模式：當某製程的規格難度陡升時，業界的第二條路不是改進該製程，而是把設計移到規格較鬆的區間。**
