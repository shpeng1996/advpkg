# METHODS OF FABRICATING GLASS PANELS TO FORM GLASS CORE PACKAGE STRUCTURES（Intel，family 98368460）

## 核心主張 / Key Claims
1. 被處理的既不是 TGV 孔壁、也不是玻璃的上下表面，而是**玻璃核心的側壁（切割後的邊緣）**。
2. **側壁塗層材料明載為高分子。**
3. 其餘結構為常規：玻璃核心上的 build-up 層、貫穿核心的 TGV 內含導體。

## 關鍵數據 / Key Data Points
⚠ **摘要無任何量化值**（無塗層厚度、無高分子種類、無強度數據）。

## 新增知識 / New Knowledge Added
- ⭐⭐⭐ **「玻璃載板／核心的邊緣韌性」自 ASE 的一則定性表述，首次進入排他權層，且解法被指認為邊緣塗層。**
- ⭐⭐⭐ **「附著性／界面已是一階設計限制」論述（2026-09-27 升格）取得第四個技術域**：既有為 TGV 孔壁、RDL/passivation 界面、玻璃載板邊緣韌性（ASE，定性）；**本件把第三項從定性升為具體工程手段。**
- ⭐⭐ 與同申請人同日之 US20260005114A1（框）合觀：**Intel 在 2026 年初對玻璃的「外圍」同時下了兩注，且兩注互補而非互斥**——與 2026-09-27 記錄的「四條互斥橋幾何」型態不同，顯示 Intel 在不同子問題上採不同的下注模式。

## 矛盾或修正 / Contradictions / Corrections
- ⚠⚠ **2026-08-27 Tom's Hardware 記載「邊緣應力自 95 MPa 降至 49 MPa（edge-coating）」，與本件手段相同。但本件摘要無數值，該 95→49 MPa 不得歸因於本件。** 兩者應分別標註來源層級（展品／報導層 vs 排他權層）。
