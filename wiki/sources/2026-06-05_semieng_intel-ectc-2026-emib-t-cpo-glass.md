# SemiEng: Packaging Technologies Redefine AI And HPC Scalability Limits At ECTC 2026

## 核心主張 / Key Claims

- EMIB-T FLI bump pitch: **25 µm**; package up to **120×120mm**; **>9× reticles** of Si content per package
- EMIB-T signal: **>12 Gb/s** for HBM4e; **64 Gb/s UCIe** — near-monolithic chiplet performance
- CPO: glass fan-out couplers + V-groove glass coupler interface — low-loss, pluggable, high-volume manufacturing compatible
- Glass substrates: copper-filled TGVs survive harsh thermal cycling; glass stays flat (vs. organic warpage)
- Hybrid bonding research: ultra-low temperature D2W; EV Group 100% chip-to-wafer bond overlay control at high speed

## 關鍵數據 / Key Data Points

| 指標 | 數值 |
|------|------|
| EMIB-T FLI bump pitch | 25 µm |
| EMIB-T package size | up to 120×120 mm |
| Si content per package | >9× reticles |
| HBM4e signal speed via EMIB-T | >12 Gb/s |
| UCIe interface speed | 64 Gb/s |

## 新增知識 / New Knowledge Added

- EMIB-T 的 FLI 25µm pitch 和 120mm×120mm 封裝尺寸為 ECTC 2026 首次公開量化。
- Intel EMIB-T 整合 UCIe 64 Gbps 介面，確認 UCIe 已是 Intel AI 加速器生態系核心協定。
- 玻璃基板 TGV 可靠性：在嚴苛熱循環測試中零失效——這是 Intel Foundry 玻璃基板最完整的可靠性數據。
- V-groove 玻璃耦合器介面：相比 FAU 直接插纖更穩固——CPO 量產路徑的製程創新。
- SPIL 合作：fan-out embedded bridge 中的 3D SRAM chiplet 整合——OSAT 在 EMIB-T 生態系的角色。
