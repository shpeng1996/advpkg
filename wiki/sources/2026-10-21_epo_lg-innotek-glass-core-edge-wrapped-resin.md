# 玻璃的問題在邊緣：第三家公司、第三種結構

## 核心主張 / Key Claims

1. 電路板能在**玻璃核心基板之玻璃層側部**抑制**崩邊（edge chipping）、裂紋，及／或板材分層**之
   **發生、傳播與擴大**。
2. 結構為**三段式樹脂層**：
   - **側樹脂層**沿圓周方向環繞玻璃層側部；
   - **上樹脂層**置於玻璃外側上部並朝上表面中央延伸；
   - **下樹脂層**置於玻璃外側下部並朝下表面中央延伸。
3. ⭐ **請求項把幾何關係寫死：上／下樹脂層「延伸寬度大於其垂直方向厚度」**
   ——即**覆蓋範圍（橫向）被要求大於保護層本身的厚度（縱向）**。
4. 玻璃層具貫穿上下表面之通孔（TGV）。

## 關鍵數據 / Key Data Points

⚠⚠ **零量化值**：樹脂層厚度、延伸寬度、玻璃厚度、側部角度、崩邊抑制的量測對照全部未給。
⚠ OPS 回傳 IPC/CPC 為空。

## 新增知識 / New Knowledge Added

- ⭐⭐⭐ **既載「玻璃基板的良率瓶頸在邊緣與切單，而非穿孔本身」取得第三條獨立證據，且為第三種解法型態。**
  既有兩條（[[technologies/glass-substrate]]）：
  ①**LG Chem CN122342272A**（改切單方式：先成形保護層再切）、
  ②**邊緣應力塗層 95 → 49 MPa**（塗一層以降低邊緣應力）。
  本件為**③以幾何定義的包邊結構整圈封住側部並反折到上下表面**。
  ➜ 📌 **三種解法分別作用在「切單製程」「表面應力」「幾何封閉」三個不同環節**
  ⇒ 該論述自「成立」升格為「**成立且已出現三條互不重疊的工程路徑**」。
- ⭐⭐⭐ **與既載 Intel JP2026059728A（框式玻璃核心之邊緣塗覆：buffer layer ＋ frame，2026-09-14 收錄）
  構成「同一問題、兩家不同公司、兩種結構」。**
  Intel 的做法是**玻璃邊緣內縮 ＋ 外圈 buffer ＋ 外框**（邊緣後退並加框）；
  LG Innotek 的做法是**樹脂直接包覆側部並反折**（不後退，直接封）。
  ➜ 📌 **「邊緣保護」已分化為「後退加框」與「包覆反折」兩條路線**，可作為後續判讀同類專利的分類軸。
- ⭐⭐ **請求項同時列出 edge chipping / cracks / board separation 三種失效模式**
  ⇒ 支持既載「**同一名詞涵蓋多個獨立驗收項**」一族規範（既有：粗糙度須標技術域、
  切割品質至少五項、改善百分比須標對照基準、翹曲五項強制標註）。
  ➜ 📌 **新增一項：「玻璃邊緣品質」亦非單一驗收項，至少含崩邊／裂紋／分層三者；
  引用任何邊緣相關數字須標註量的是哪一項。**
  ⚠ 既載唯一的邊緣寬度數字（ASE 再用玻璃載板受損區寬 ~43 µm）已明確標註**不是門檻值**，
  本件亦無門檻 ⇒ **該族至今無任何驗收門檻值。**
- ⭐ **「寬度 > 厚度」寫入請求項**，與既載 Deca US20260136970A1
  「橋 footprint 內的第一 pitch／footprint 外的第二 pitch」同屬**把空間邊界幾何化寫入請求項**之手法
  ⇒ 第二個落點，且首次用於**保護結構**而非互連密度。
