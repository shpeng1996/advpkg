# 混合接合表面／界面反應機制綜述（中科院微電子所）

## 核心主張 / Key Claims

1. **標準流程為四段**：**CMP → 表面活化 → 室溫預接合 → 退火**。
2. ⭐⭐ **原文明文直述：由於材料系複雜且流程冗長，接合表面與界面的反應機制「remains unclear」。**
3. 綜述三軸：①**電漿／化學處理**對金屬／介電表面組成與結構之影響；②**界面力演化、水分子與接合波**；③金屬／介電接合機制與**與可靠度相關的副反應**。
