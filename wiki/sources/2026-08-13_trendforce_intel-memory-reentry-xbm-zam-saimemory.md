# TrendForce：Intel CEO 暗示重返記憶體；ZAM、Saimemory、XBM CPU 堆疊路線圖浮現

## 核心主張 / Key Claims

- **Intel CEO Lip-Bu Tan 暗示重返記憶體市場**：Tan 表示記憶體市場「已成熟可創新」，並以「將記憶體直接堆疊在 CPU 上頗有道理」表達方向性意向（Tom's Hardware 報導）；前 SK Hynix CEO 李錯熹（Seok-Hee Lee）加盟被突出提及
- **Z-Angle Memory（ZAM）架構首次揭露**：Intel 開發中的低功耗堆疊 DRAM 架構，由 8 個 DRAM die 加邏輯控制器組成，設計目標是降低功耗、散熱與成本，定位為 HBM 替代方案（Business Post 報導）
- **Saimemory JV 成立**：Intel 與日本軟銀（SoftBank）組建合資公司 Saimemory，支援 ZAM 技術研發與商業化
- **XBM 路線重申**：Intel XBM 專利利用 UCIe 取代矽中介層（silicon interposer），實現 CPU 與記憶體 3D 直接堆疊，降低延遲與功耗；商業化預計 2030 年後（TrendForce / Wccftech 確認）
- **潛在 Terafab 記憶體生產**：有推測認為 Intel 可能在 Elon Musk 主導的 Terafab（2028 年最早投產）生產下一代記憶體

## 新增知識 / New Knowledge Added

- **ZAM（Z-Angle Memory）首次記錄**：完全新型架構，相比 wiki 既有 XBM 技術頁（2026-07-08 收錄）大幅擴展——ZAM 是獨立的 HBM 替代路徑，而 XBM 是無中介層記憶體整合路徑；兩者在方向上互補
- **Saimemory JV 首次記錄**：Intel-SoftBank 合資公司，專注支援下一代記憶體技術（ZAM 方向）
- **李錯熹（Seok-Hee Lee）確認加盟**：前 SK Hynix CEO 轉任 Intel，主導記憶體創新戰略——進一步強化了 Intel 在記憶體領域的人才佈局
- **Intel 記憶體重返定性框架**：非傳統 DRAM 商品市場，而是以 CPU-memory 3D 堆疊和 AI 推論優化的 next-gen 記憶體為核心
