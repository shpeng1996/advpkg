# HBM 與先進封裝材料市場 2027–2037（報告發布公告）

## 核心主張 / Key Claims
1. HBM 自 8-Hi、12-Hi 邁向 **16-Hi 及更高**；基板 build-up 層數與封裝本體面積同步增加。
2. **銅對銅混合接合預期取代堆疊內的微凸塊。**
3. **玻璃核心基板與玻璃中介層正進入認證階段。**
4. **面板格式封裝為晶圓格式的後繼者，仍在開發中。**
5. 熱管理自傳統 lid 延伸至 **micro-channel lid 與直接對矽的微流道冷卻**。

## 關鍵數據 / Key Data Points
⚠⚠ **本次僅取得發布公告，報告全文未取得；公告中無任何絕對數值**（市場規模、CAGR、分項佔比均未揭露）。唯一可記錄者為方法論：
- 預測期 **11 年至 2037 年**，以 2026 年固定美元計價
- 三情境：**base / bear / bull**
- **以 CR1、CR3 與 HHI（Herfindahl-Hirschman Index）衡量各材料區隔的集中度**
- 生產集中於韓、台、日，美國產能擴張中

## 新增知識 / New Knowledge Added
