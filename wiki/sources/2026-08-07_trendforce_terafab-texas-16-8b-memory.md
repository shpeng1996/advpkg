# Tesla Terafab 德州 $16.8 億一期；記憶體工程師招募 / Terafab Texas $16.8B First Phase

## 核心主張 / Key Claims

- **一期投資 $16.8B 正式確認**（路透社 2026-08-06），遠低於先前 $55B 估計；但若後續擴建，總投資上看 $119B
- 選址：德州 Grimes County；規模 ~1 億平方英尺；3,000 工作崗位
- **功能定位**：完全垂直整合——邏輯晶片、記憶體、先進封裝、測試全在一棟屋簷下
- **記憶體工程師職缺**（Tesla 官方職位列表）：端對端 DRAM 製程整合、sub-20nm DRAM、新興記憶體（MRAM/RRAM/3D DRAM）
- Elon Musk 定性：「最史詩級的晶片製造計畫⋯邏輯+記憶體+先進封裝全在一起」
- **近期供應**：Micron「為 Tesla 留出空間」；AI5 = Samsung+TSMC 分攤；AI6 = Samsung 包辦；AI6.5 = TSMC
