# NVIDIA Reportedly Halves Vera Rubin SOCAMM Capacity as Memory Costs Near 29% of System BOM

## 核心主張 / Key Claims

- **NVIDIA 削減 SOCAMM 容量**：Vera Rubin NVL72 每塊 Vera CPU SOCAMM 從 192GB → **96GB**；總 Vera CPU 記憶體從 55TB → **28TB**；GPU HBM4 不變（20.7TB/rack）
- **記憶體 BOM 壓力**：若維持原規格，記憶體佔 VR200（估 $210 萬）BOM 約 **29%**，遠超 NVIDIA 偏好的 20% 上限
- **成本數字**（GF Securities）：原估 LPDDR5X 成本 $120 萬/rack → 削減後約 **$58.6 萬**，最低可降至 **$29.3 萬**（1/4 容量）
- **HBM4 定價展望**（Bernstein）：2027 年 HBM4 ASP 預測 **$53/GB**
- **LPDRAM 供應缺口**：Samsung + SK hynix + Micron 合計配額僅滿足 NVIDIA 需求的約 **60%**
- **NVIDIA + SK Group $500B LOI**：多年期記憶體供應（SK hynix HBM4 + LPDDR5X SOCAMM）+ 2GW AI 資料中心 + AI 工廠
