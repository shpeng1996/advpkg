# Huawei 7.2Tbps NPO vs CPO — Near-Packaged Optics as China's Optical Interconnect Strategy

## 核心主張 / Key Claims

- Huawei 在 CIOE 2026 發布 7.2Tbps NPO（Near-Packaged Optics）模組，挑戰 NVIDIA/Broadcom/TSMC 主導的 CPO 生態
- 7.2Tbps 規格：36 通道 × 200Gbps；超越 Broadcom CPO 光引擎 6.4Tbps
- NPO 架構差異：整合於 PCB 板層（非晶片封裝內）；可插拔、可替換個別故障元件
- Huawei 主導「OPEN NPO」聯盟（China Mobile Research Institute + JD Cloud + 20+ 供應鏈夥伴）——中國首個 NPO MSA
- 3.2Tbps NPO 2026 年實際部署；7.2Tbps 未來兩年內普及

## 關鍵數據 / Key Data Points

| 指標 | 數據 |
|------|------|
| Huawei NPO 頻寬 | 7.2Tbps（36ch × 200G） |
| Broadcom CPO 對比 | 6.4Tbps |
| CPO/NPO 市場規模 2025 | ~$100M |
| CPO/NPO 市場規模 2030 預測 | $39B+（TrendForce） |
| OPEN NPO 技術規格發布 | Q3 2026 |
| NPO 大規模商業化目標 | 1H 2027 |

## 新增知識 / New Knowledge Added

1. **NPO（Near-Packaged Optics）**正式登場作為 CPO 的中間過渡路線——此前 wiki 僅涵蓋 CPO；NPO 為 PCB 級整合，非封裝級
2. Huawei 以 NPO 路線繞開 2.5D/3D 先進封裝技術壁壘（後者由 TSMC/西方廠商主導）
3. CPO/NPO 合計市場 $39B（2030）——提供 CPO 市場規模量化基準
4. 中國 CSP（阿里巴巴、騰訊）採 NPO 為中期主策略；西方（Meta、Microsoft）同時推進 NPO via OCI-MSA
