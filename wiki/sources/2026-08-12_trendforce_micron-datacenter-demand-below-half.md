# TrendForce：Micron 資料中心需求滿足率不足50%

## 核心主張 / Key Claims

1. Micron 資料中心 DRAM 需求滿足率**不足 50%**（2026-08-10 KeyBanc Tech Leadership Forum，SVP Sumit Sadana）
2. 2027 年供需缺口預期進一步惡化，比 2026 更緊俏
3. DRAM 是客戶今日面臨的**第一大瓶頸**（超越電力、廠房、邏輯晶圓）
4. Micron 是美國**唯一前端記憶體晶圓廠**廠商，可向客戶收取「美製溢價」，已納入 SCA 合約定價
5. 16 份 SCA 合約到期多為 2030 年，含 take-or-pay 條款，覆蓋約 50% 營收

## 關鍵數據 / Key Data Points

| 指標 | 數值 |
|------|------|
| DC DRAM 需求滿足率 | <50% |
| SCA 合約數量 | 16 份 |
| SCA 到期年份 | 大多數至 2030 |
| SCA 營收佔比 | ~50% |
| 3Q26 伺服器 DRAM 合約價漲幅 | +13–18% QoQ（TrendForce 預測）|
| SCA 價格上限基準 | CQ2 2026 定價 |
| 未來 SCA 價格上限 | 以簽約時市場價格為基準 |
| 2027 供需 | 比 2026 更緊（Micron 官方預測）|

## 新增知識 / New Knowledge Added

- **<50% 資料中心需求滿足率**：這是迄今最直接的量化供需缺口聲明，比一般「供不應求」描述更具體。
- **「美製溢價」**：確認 Micron 美國前端晶圓廠已讓其在 SCA 定價中取得溢價，Samsung（美國=邏輯代工）及 SK Hynix（美國=後端封裝）無法比照。
- **SCA 價格上限機制演進**：舊 SCA（前 16 份）以 CQ2 為上限基準；新 SCA 將隨簽約時市場價格動態調整（去除頂蓋固定化風險）。

## 矛盾或修正 / Contradictions / Corrections

- 無明顯矛盾；與 wiki/entities/micron.md 中「16 SCA 合約」記錄一致（但<50% 需求滿足率為首次明確量化）。
- Micron 同時表示「開始適度放緩漲價幅度」，看似與 2027 更緊缺的預測矛盾，但 Sadana 解釋為「多管道平衡」策略。
