# Hanwha Semitech SHB2 Nano

## 核心主張 / Key Claims
1. 第二代混合接合機 **SHB2 Nano**，標示**對準誤差 0.1 µm（100 nm）**。
2. **2026 上半年進入客戶端性能測試**；第一代於 **2022-01 交付**。
3. 無凸塊、銅面直接接合，接合界面近乎零間隙。
4. 目標應用 **HBM**；報導稱 Samsung 已將 HB 用於 **HBM4**，計畫於 **HBM4E 有限商用化**。
5. 公司 TCB 機種 **SFM5 Expert 於 2025 年銷售額逾 ₩900 億**。

## 關鍵數據 / Key Data Points
| 項目 | 值 |
|------|----|
| 對準誤差 | **0.1 µm**（⚠ **未標註是否 3σ**，屬規格宣稱非量產實績） |
| 第一代交付 | 2022-01 |
| 第二代客戶測試 | **2026 H1** |
| TCB 業務規模 | **> ₩900 億（2025）** |
| 對照：Besi Kinex 量產現況 | 100 nm @ 3σ |
| 對照：Hanmi 第二代原型 | **2026 年底**；量產採用 ~2029 |

## 新增知識 / New Knowledge Added
1. ⭐⭐⭐ **結清 2026-09-22 空缺：「若 HB 確於 2027 年底導入 HBM4E，而 Hanmi 要到 ~2029，該世代機台由誰供應？」** ➜ **Hanwha Semitech 的第二代機在 2026 H1 即進入客戶測試，比 Hanmi 的「2026 年底原型」早約一年。** Hanmi 並非唯一的韓系選項，**其缺席不等於韓系缺席**。
2. ⭐⭐ **對準數值與 Besi Kinex 同級（100 nm）** ⚠ 但 Besi 的是**量產實績且標註 3σ**，本篇是**規格宣稱且未標註統計量**，不可直接等同。本 wiki 2026-09-21 新設的「數值須標註重複性／統計量」規則在此適用。
3. ⭐⭐ **TCB 與 HB 的營收結構再次顯示兩者不同曲線**：Hanwha 的 TCB 已是 ₩900 億級業務，HB 仍在客戶測試階段——**與 Hanmi 同型**（TCB 領先、HB 落後）。➜ **「TC bonding 與 hybrid bonding 不是同一條學習曲線」擴展為兩家公司的共同模式，而非 Hanmi 個案。**
