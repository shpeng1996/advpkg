# Samsung NRD-K Line 2 Repurposed for 2nm HBM5 Base Dies / 三星 NRD-K 二號線轉型 2nm HBM5 邏輯底層

## 核心主張 / Key Claims

- 三星考慮將 Giheung NRD-K Line 2（正在建設中）從 R&D 角色轉為量產代工廠，主攻 **2nm HBM5 邏輯底層晶片（base die）**
- HBM5 邏輯底層採用三星 **GAA 架構 2nm 製程**，所需運作速度比 HBM4E 高出 **>50%**
- NRD-K Line 2 預計 **2H28** 開啟，規模相對小，將作為「送洗廠（send fab）」補充主量產線
- 設備採購訂單尚未下達，方向仍可能調整
- 三星 NRD-K 複合體：KRW **20 兆**總投資，三條線，2030 年完成；Line 1 已於 2024 年底完工

## 關鍵數據 / Key Data Points

| 項目 | 數值 |
|------|------|
| NRD-K Line 2 開啟時程 | 2H28 |
| HBM5 邏輯底層製程節點 | GAA-based 2nm（三星） |
| HBM5 相對 HBM4E 速度提升要求 | >50% |
| NRD-K 總投資 | KRW 20 兆（3 條線，至 2030） |
| 主要目標客戶 | NVIDIA |

## 新增知識 / New Knowledge Added

- **首次記錄 HBM5 邏輯底層的製程節點**：確認為 GAA 2nm（三星自有），速度要求 >50% 高於 HBM4E，這是 wiki 中 HBM5 最具體的技術規格。
- **NRD-K「送洗廠」概念**：三星正在探索以小型特化廠補充主量產線，類似 TSMC 外包 CoW 給 OSAT 的邏輯，反映 HBM 需求量已超越單一廠區容量。
