# ASMPT US20260114310A1

**家族 / Family**：99442154　**公開日**：2026-04-23　**分類**：H10W72/0x 系八個子群（**全部落在打線接合**，無電鍍、無光微影）

## 核心主張 / Key Claims

- 以打線工具在基板焊墊上**成球接合**，拉高工具延長線段。
- **以工具把線段上某一點壓向球接合的一部分，形成「弱化點（weakened portion）」。**
- **移動工具將線段拉直並於弱化點折斷**，形成垂直線柱互連。

## 關鍵數據 / Key Data Points

| 項目 | 值 |
|------|-----|
| 節距、線徑、柱高、良率 | **全部未給**（標題稱 fine-pitch，摘要無數） |
| CPC 分布 | **100% 打線接合子群** |

## 新增知識 / New Knowledge Added

- ⭐⭐ **垂直線柱（wire stud）路線仍在被設備商主動推進。** 既載對垂直互連的記錄集中在 **TMV／鍍銅柱／TSV／TGV**；本件顯示**打線機路線**在 2026 年仍有新排他權，且手段是**機構動作（壓出弱化點 → 拉直折斷）**而非材料或微影。
- ⭐⭐ **既載橫向論述「當某製程規格難度陡升時，業界的第二條路不是改進該製程，而是把設計移到規格較鬆的區間」新增第五個落點。**
  既載四例：GlobalFoundries（對準精度自機台 → 微影）、Apple／Deca（以 fan-out 放寬 bump pitch）、EVG WO2026008137A1（輪廓精度自模具 → 材料擺位）、hybrid taper–grating（光纖對準 → 晶片側錐＋光柵）。
  **本件**：**垂直互連的難度自「鍍得準」移到「折得準」** —— 即自濕製程與微影維度移到**機構動作維度**。
- ⭐ **與同輪 Amkor US20260293689A1 的對照**：兩者都在處理「封膠中的垂直互連」，但 **Amkor 從結構層（屏蔽兼用）切入，ASMPT 從成形手段切入** ⇒ 同一問題的兩個不同產業位置各自布局。
