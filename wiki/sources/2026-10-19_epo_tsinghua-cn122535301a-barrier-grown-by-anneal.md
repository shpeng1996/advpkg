# 清華：合金層＋銅＋退火，原位生成擴散阻障層（專利訊號）

## 核心主張 / Key Claims

1. 流程：蝕刻凹槽露出導電區 → 沉積絕緣層 → 蝕開底部 → **沉積合金層** → 填銅 → **退火，使絕緣層與合金層之間原位形成擴散阻障層** → CMP 平坦化。
2. 宣稱效果：**有利於焊盤節距縮小與更高互連密度。**

## 關鍵數據 / Key Data Points

⚠ **全篇零量化值**（無溫度、無時間、無節距、無阻障層厚度）。
⚠ **「有利於節距縮小」無任何數字支撐**，不得作為任何節距論述的依據。

## 新增知識 / New Knowledge Added

- ⭐⭐⭐ **擴散阻障層自「沉積的一層」變成「退火長出來的反應產物」。**
  ⇒ 📌 **「把問題移進材料裡」系列的第四個落點**（既有三例見 [[entities/atotech]] 穩定化細晶製程等）。
  本次換到的是**步驟數**：少一道沉積、多一次退火。

## 矛盾或修正 / Contradictions / Corrections

- ⭐⭐⭐ 📌 **與既載「退火是雙面刃」直接相撞。**
  [[entities/atotech]] 一手資料：**~10 min @ ~200 °C 保留細晶；~2 h @ 200±10 °C 造成顯著晶粒成長**
  （既載「最佳值必然是區間」第九例、首次落在時間上）。
  本件**把退火當成建設性步驟**而非須被限制的風險。
  ⇒ **立追蹤問題：本件的退火溫度／時間窗是否落在 Atotech 所界定的晶粒成長窗內？
  若是，則阻障層的生成與銅晶粒的劣化共用同一個製程視窗，兩者必須被當成同一個取捨來處理。**
  ⚠ 本件未給任何溫度／時間 ⇒ 問題暫無法判定，列入追蹤。
- ⚠ 學研單位申請案，不預示量產。發明人 CAI JIAN（蔡堅）為清華 3D 整合長期研究者。
