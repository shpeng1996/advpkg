# Tom's Hardware: LG-PRI enters chip packaging with Laser Direct Imaging machine

## 核心主張 / Key Claims

1. **LG Electronics Production Technology Institute (LG-PRI)** 與一家 OSAT 簽約，供應**無光罩雷射直寫成像（LDI）微影工具**，用於先進封裝 RDL 圖形化
2. 最高解析版本：1.5 µm 線/間距 → 線路節距約 **3 µm**；以吞吐量換取解析度
3. 背景：TSMC CoWoS 持續供應緊張（供需缺口從 ~20% 收窄至 ~10%，但仍顯著）
4. LG 傳統上為消費電子/顯示器廠商，此舉標誌跨界進入半導體封裝設備市場

## 關鍵數據 / Key Data Points

| 指標 | 數值 |
|------|------|
| 解析度 | 1.5 µm L/S（→ ~3 µm 線路節距） |
| 技術類型 | 無光罩雷射直寫成像（LDI） |
| 應用 | RDL 金屬互連圖形化（CoWoS 等先進封裝） |
| 競爭者 | Mycronic、Orbotech(KLA)、CFMEE PLP 2000 |

## 新增知識 / New Knowledge Added

- **LG-PRI 進入封裝設備市場** = 非傳統半導體設備廠商進入 RDL 微影領域的新案例（繼 CFMEE 中國本土設備之後）
- **無光罩 LDI 在先進封裝中的商業化推進**：與 CoWoS 供應緊張直接相關，代表 OSAT 為多元化工具供應商而評估 LDI

## 矛盾或修正 / Contradictions / Corrections

- 無明顯矛盾；補充 CoWoS 設備生態多元化現況
