# SemiconSam：主宰 CMP 者勝

⚠ **刻意收錄的舊文（2025-09）**，理由見「新增知識」第 1 點。

## 核心主張 / Key Claims

1. 混合接合專用 CMP 設備 **AMAT 市占 100%**；整體 CMP 市占 60%。
2. Ebara 與 KC Tech **無混合接合 CMP 實績**。
3. 混合接合的勝負由 CMP 能力決定，而非接合機。
4. Hanmi Semiconductor 預計 2027 銷售 HBM 用混合接合機。

## 關鍵數據 / Key Data Points

| 項目 | 數值 |
|------|------|
| **AMAT 混合接合 CMP 市占** | **100%** |
| AMAT 整體 CMP 市占 | 60% |
| Samsung HB 導入點（當時說法） | HBM4E 16-high |
| SK hynix HB 導入點（當時說法） | HBM4E 20-high |
| Hanmi | 2027 售 HB 機；目標 HBM6 於 2027 年底 |
| AMAT 持 Besi 股權 | 9%（2025-04） |

## 新增知識 / New Knowledge Added

1. ⭐⭐ **與本輪其他兩篇合併後產生本 wiki 尚未記錄的結構性結論：pitch 微縮的第一限制目前由單一供應商掌握。** 2026-09-19 已確立限制鏈第一層是 CMP／表面製備（比機台對準嚴格 500 倍）；本文指出該層設備由 **AMAT 獨占**。➜ **整個產業 pitch 微縮的速率上限，實質由一家設備商的製程能力決定**，而非由接合機的三方競爭（Besi／EVG／ASMPT）決定。這也回頭解釋 AMAT 持股 Besi 9% 的布局邏輯：**控制限制層，再參股非限制層**。
2. **Hanmi 為本 wiki 尚未建頁的第四家混合接合機供應商**（與 Besi／EVG／ASMPT 並列），列入待追蹤。

## 矛盾或修正 / Contradictions / Corrections

- ⚠ **時程記載與本 wiki 現行版本不一致，但屬演進而非矛盾。** 本文（2025-09）稱 SK hynix 自 **HBM4E 20-high** 導入混合接合；本 wiki 現行記錄（2026-08/09 多來源，含 Hot Chips 2026）為 **SK hynix 明確排除 HBM4E、延至 HBM5**。➜ 記錄為時程演進的中間點，**不修改現行結論**。
- ⚠ 「AMAT 100% 獨占」為單一來源主張，無第三方市占統計佐證，列為**待佐證**。
