# Silicon Box：RDL 內建金屬密封環以均勻化電鍍（EP4697377A1）

**公開號** EP4697377A1｜**專利家族** 93211897｜**公開日** 2026-02-18｜**申請人** Silicon Box Pte Ltd (SG)
**發明人** **Sehat Sutardja**（Silicon Box 創辦人、Marvell 共同創辦人）｜**IPC** H10W70/099、H10W70/65、H10W74/117
**同日同申請人姊妹案**：EP4697378A1（家族 93284125）

## 核心主張 / Key Claims

1. 晶圓或**面板級**扇出製程：第一介電層 + via → RDL → 第二介電層 + via → bump 結構。
2. 關鍵限定：**RDL 內含一金屬密封環（metal sealing ring），用以在電鍍製程中延長導電路徑**。

## 關鍵數據 / Key Data Points

無量化數據（未給電鍍厚度均勻度改善百分比）。

## 新增知識 / New Knowledge Added

- **把面板級良率瓶頸指向「大面積電鍍均勻度」**。大面板上遠離電鍍接點的孤立 RDL 特徵所見電流密度與近端不同；金屬密封環作為分散式導電路徑，可壓平整片面板的鍍層厚度分布。
- 發明人是**創辦人本人**，對一件 2024 優先權的申請案而言，通常標示核心架構主張而非增量改良。這使本案在 Silicon Box 的 IP 組合中有指標意義。
- 與本輪其他來源構成**三方獨立佐證**：面板級的真瓶頸在**registration / uniformity（對位與均勻度）**，而非微影解析度。
  1. Silicon Box（新加坡新創）→ 電鍍均勻度
  2. Shanghai Xianfeng（中國材料側）→ 對位標記抗氧化（CN122476946A）
  3. SemiEngineering / Yole / Bruker（產業分析側）→ 翹曲導致 die shift 與對準誤差
  這是本輪最強的收斂訊號。
