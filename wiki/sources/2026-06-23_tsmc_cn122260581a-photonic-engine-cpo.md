# TSMC Patent CN122260581A — Photonic Engine Package with Grating Couplers

## 核心主張 / Key Claims (Patent Signal)

- 台積電於 2026-06-23 公開之專利揭示：光子引擎封裝，包含光柵耦合器與微透鏡陣列，與電子晶片整合於同一封裝體內
- Method of forming a photonic engine by bonding photonic die (with grating couplers + microlenses) to electronic dies
- Directly maps to TSMC COUPE™ architecture targeted for 2H2026 HVM

## 關鍵數據 / Key Data Points

| Item | Value |
|------|-------|
| Applicant | TSMC |
| Key elements | Grating couplers + microlenses on photonic die |
| Integration | Photonic die bonded to electronic die(s) |
| Publication | 2026-06-23 |
| Target product | COUPE™ (Co-packaged Optics Using Photonic Engines) |

## 新增知識 / New Knowledge Added

- Confirms grating coupler + microlens as TSMC's chosen optical coupling approach (vs Intel's V-groove for edge coupling)
- TSMC and Intel are pursuing different CPO coupling strategies: TSMC = surface-normal grating; Intel = edge-coupled V-groove glass waveguide
