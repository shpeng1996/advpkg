# HyperFRAME：AMAT 是押注還是避險？

## 核心主張 / Key Claims

1. AMAT 的軸線是**「收斂」（convergence）**——前段 fab 與後段封裝製程界線模糊化。
2. 擴張指標是「每片晶圓上良率關鍵接觸點的數量」，而非單一 hero tool。
3. 把邏輯級磊晶延伸至 DRAM 週邊電晶體；把 fab 級量測部署到封裝基板。
4. 對接合方式的不確定性採取避險而非押注。

## 關鍵數據 / Key Data Points

| 項目 | 數值 |
|------|------|
| Centura Prime Epi 佔地 | −20% |
| 超薄 die 厚度 | 標準晶圓的 1/25 |
| 支援 HBM 層數 | 12、16 及以上 |
| HBM 市場 CAGR | 約 20% 中段，至 2030 年代初 |
| eBeam 量測靈敏度 | sub-10 nm（跨多種基板） |

## 新增知識 / New Knowledge Added

1. **與同輪 SemiconSam 形成對照，兩種讀法並列**：若 AMAT 確實獨占混合接合 CMP，其對外論述卻刻意淡化單一技術押注——（a）獨占地位使其無須押注；或（b）AMAT 判斷接合方式仍未收斂，故以量測與製程廣度避險。本 wiki 記錄兩種讀法，不擇一。
2. **「fab 級量測下沉到封裝」是本 wiki「量測為第三個結構性瓶頸」論述的設備側佐證**，與 Bruker 把 AFM／AFP 導入封裝（同輪）方向一致，構成兩個獨立廠商的同向動作。
3. 超薄 die = 標準晶圓 1/25，與 2026-08-18 AMAT 官方部落格記錄**交叉一致**。

## 矛盾或修正 / Contradictions / Corrections
- 無 CMP 粗糙度、平坦度、pitch 路線圖或營收數字，價值主要在策略面。
