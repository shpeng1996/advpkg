# AMD：混合接合層彈性繞線（專利訊號）

## 核心主張 / Key Claims

1. 以**蝕刻停止層**，使連到混合接合層的 via **可同時終止於兩種落點**：晶粒表面 contact pad，或頂層金屬中的 **buried conductive pad**。
2. 分類全在 H10W20/\*（元件內部繞線）與 H10W70/611，**無接合製程類（H10W72/9xx）** ⇒ 為**設計／繞線層**布局，非製程層。

## 關鍵數據 / Key Data Points

⚠ **全篇零量化值**（無節距、無層數、無深度、無良率）。

## 新增知識 / New Knowledge Added

- ⭐⭐⭐ **本 wiki 第一件 AMD 混合接合層專利。** [[entities/amd]] 既載全為產品規格（MI355X／MI455X／CoWoS-L／12×HBM4／40.26 PFLOPS），
  **排他權層為空白**；本件使 AMD 自「混合接合的需求方」首次成為「混合接合結構的權利持有人」。
- ⭐⭐⭐ 📌 **「接合墊必須在同一平面」這個隱含前提首次被挑戰。**
  既載混合接合全部論述（Cu dishing 必為區間、Ra <0.1–0.2 nm、CMP 為限制層、3–5 nm 控制能力 vs 產線 5–25 nm）
  都建立在「接合面是單一平坦面、墊在該面上」。本件讓 via **穿過接合層落到更深的埋入墊**。
  ⇒ **立追蹤問題：若落點可在兩個深度，則平坦度須管控的面積與 dishing 規格是否隨之改變？**
- ⭐⭐ **「局部高密度」系列論述新增垂直向版本**：既有各例（橋的 footprint、載體密度上限、SEMCO 無核心內嵌有機橋）
  都在**平面**上劃分疏密；本件在**深度**上劃分落點。
