# CPO 交換器量產進度（2026-07-30，二手轉述 TrendForce）

⚠ **二手**；且發布日逾本 wiki 6 個月窗口外約 3 個月。收錄理由：補 CPO 供應鏈**時程表**，非補量化規格。

## 核心主張 / Key Claims

1. **NVIDIA Spectrum-X（與 TSMC 共同開發、COUPE 封裝）與 Broadcom Bailly 皆已量產**；Bailly 已完成含 Meta 的超大規模業者部署驗證。
2. **CPO 交換器的放量期在 2027–2028**，2026 下半年為擴大期。
3. ⭐⭐ **Samsung：2026-03 完成矽光 PDK；計畫 2028 量產、2029 提供完整 CPO 服務**，並與 HBM、代工、封裝**綁售**。
4. **UMC 2026-07 宣稱交付首批 300 mm 量產矽光晶片**（新加坡廠，Silith 技術）；**GlobalFoundries 2025-11 併購 AMF**。
5. 瓶頸被指為**光引擎的熱管理與良率**（可能侷限於「a handful of suppliers」）、矽光建廠週期，以及**先進封裝（2.5D/3D）本身的供給吃緊**。

## 關鍵數據 / Key Data Points

| 項目 | 值 |
|------|-----|
| Spectrum-X 交換容量 | **最高 400 Tb/s** |
| CPO 帶來的交換器頻寬躍升 | **51.2 → 102.4 Tb/s** |
| Bailly 相對可插拔模組之功耗 | **最多降低 70%** |
| CPO 交換器放量期 | **2027–2028** |
| Samsung 矽光 PDK 完成 | **2026-03** |
| Samsung 矽光量產 | **2028** |
| Samsung 完整 CPO 服務 | **2029** |
| UMC 300 mm 矽光量產宣告 | **2026-07** |
| GF 併購 AMF | **2025-11** |

⚠ 本文**未給**出貨量、port 數、對準公差或接合節距。

## 新增知識 / New Knowledge Added

- ⭐⭐⭐ **與本輪專利軌形成強共振**：同輪取得 **Samsung US20260040943A1（光引擎：PIC 疊於 EIC、以 PIC 基板斜面＋反射圖案轉向光路，公開 2026-02-05）**。本件則給出 Samsung 的**產品時程**（2028 量產 / 2029 完整服務）。
  ⇒ 📌 **Samsung 在 CPO 上同時具備「排他權落點」與「對外時程」，且專利公開（2026-02）早於量產宣告（2028）約兩年** —— 與本輪 Amkor bridge 之「專利領先商機宣告約 1.5–2 年」同量級。
- ⭐⭐ **Samsung 的 CPO 策略被描述為與 HBM／代工／封裝綁售** ⇒ 與既載「Samsung 以 turnkey 對抗 TSMC」之敘述一致，並把 CPO 納入該捆綁。
- ⭐ **矽光代工端出現三個新落點**（GF 併 AMF、UMC 300 mm、Samsung PDK）⇒ CPO 的**上游晶圓端**正在多元化，而本文把**封裝端**列為共同瓶頸。
