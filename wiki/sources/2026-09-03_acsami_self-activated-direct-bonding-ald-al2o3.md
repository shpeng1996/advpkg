# Self-Activated Direct Bonding via ALD Al2O3 (Plasma-Free, 300-mm Wafers)

## 核心主張 / Key Claims

- 報告了一種「自激活、無需電漿」的直接晶圓接合新機制，藉由原子層沉積（ALD）Al2O3 薄膜實現，在 300 mm 晶圓上展示了無空洞接合
- Thin ALD Al2O3 film provides sufficient surface polarity and hydroxyl density for void-free room-temperature bonding without plasma activation
- Demonstrated on 300-mm wafers (production-relevant scale)
- Mechanism: high polarity + hydroxyl density of ALD Al2O3 enables direct bonding interface

## 關鍵數據 / Key Data Points

| Item | Value |
|------|-------|
| Wafer size | 300 mm |
| Activation method | None (self-activated via ALD Al2O3) |
| Standard comparison | Plasma activation (SAB/surface activation bonding) |
| Bonding quality | Void-free (demonstrated) |
| Film material | ALD Al2O3 |

## 新增知識 / New Knowledge Added

- First demonstration of plasma-free self-activated direct wafer bonding using ALD Al2O3 — opens a new process simplification path for hybrid bonding
- Current hybrid bonding (TSMC SoIC, Intel Foveros Direct, imec pilot) requires plasma activation before room-temperature bonding; this work suggests an alternative
- Particularly relevant as pitches approach 1 µm, where plasma-induced surface damage becomes an increasing yield concern
