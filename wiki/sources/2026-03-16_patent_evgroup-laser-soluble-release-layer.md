# EV Group：雷射可溶層 + 對輻射透明的載板

## 核心主張 / Key Claims
1. 產品基板經**連接層**接合至**載板**，並於連接層與產品基板之間施加**可溶層**。
2. 該可溶層**因與電磁輻射交互作用而可溶解**。
3. ⭐ **連接層與載板必須對該電磁輻射「至少大部分透明」。**
4. 同時主張據此之解接合方法。

## 新增知識 / New Knowledge Added
1. ⭐⭐⭐ **直接命中 2026-09-22 新設的空缺**：「FOPLP 翹曲峰值出現在 debonding 階段；承載板材料（鋼／玻璃／陶瓷）是此前完全沒有記錄的變數。」
2. ⭐⭐⭐ **本件補上一條本 wiki 尚未記錄的因果鏈**：
   **解接合方式（雷射穿透）→ 載板必須對該波長透明 → 排除多數金屬載板 → 載板材料被解接合製程反向決定 → 而載板材料又決定翹曲。**
   ➜ **「承載板材料是新變數」這件事不是自由變數**——它同時被 **debonding 製程**與**翹曲**兩端夾住。⚠ **此為本 wiki 推論（兩個獨立來源的交叉），非任一來源明述。**
3. ⭐⭐ **輪替規則修正**：2026-09-22 把 EV Group 移入「已確認訊號偏弱」名單。本件顯示該判斷**只在 W2W 接合題材上成立**，在**暫時接合／解接合**題材上 EVG 有訊號。➜ **名單應按題材而非按公司維護。**
