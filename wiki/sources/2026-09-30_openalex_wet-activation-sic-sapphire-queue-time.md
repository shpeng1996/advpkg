# 濕式活化之 SiC/藍寶石親水性直接接合（鄰域）

⚠ **材料體系為 SiC/藍寶石（MEMS 與功率電子），非 Cu/介電混合接合。** 收錄理由為**手段層與 queue time 層**，非性能層。

## 核心主張 / Key Claims

1. **以「硫酸浸泡 → 逆滲透水」之濕式序列達成親水活化，無需中間層**，靠凡得瓦力與氫鍵自發接合。
2. ⭐⭐⭐ **作者明言：「bonding was carried out promptly after activation」，以保存表面反應性官能基。**
3. 退火促使表面 –OH 脫水，形成 **Si–C–O–Al 與 Si–O–Al** 界面鍵結。
4. STEM 觀察到**富碳非晶界面層，厚度約 590 nm**，被認為提升界面強度。
5. 約 **100 °C**、活塞載荷 **8.73 N** 下接合，強度 **~238 kPa**。

## 關鍵數據 / Key Data Points

| 項目 | 值 |
|------|-----|
| 活化 | **H₂SO₄ → RO water**（濕式，無中間層） |
| 接合溫度 | **~100 °C** |
| 載荷 | **8.73 N** |
| 接合強度 | **~238 kPa** |
| 界面層 | **富碳非晶，約 590 nm** |
| 退火後界面鍵 | Si–C–O–Al、Si–O–Al |
| 逐片重複性、queue time 數值 | **未給**（僅定性「promptly」） |

## 新增知識 / New Knowledge Added

- ⭐⭐⭐ **既載空缺「惰性環境 Cu 氧化相門檻」之提問方式修正（自『多少溫度生成哪一相』改為『接合當下表面還剩多少氧化物』、可操作變數是 queue time）取得第二個獨立佐證。**
  既載第一例為上海大學 CN121511008A（Ar/H₂ 電漿不足以還原 Cu 氧化物 → 改檸檬酸濕式還原）。
  **本件的增量**：作者**把「活化後立即接合」寫成方法的一部分**，即**在不同材料體系中，活化表面的有效期同樣是一個須管理的製程變數**。
  ⚠ **仍無數值**（沒有「幾分鐘內」的量化窗口）⇒ **空缺不結清**，但**可自「Cu 專屬」擴寫為「活化表面之有效期為跨材料體系的通則」**（兩個獨立體系、兩個獨立團隊）。
- ⭐⭐ **「活化手段」第②軸再添濕式一例**，且本例**完全不用電漿**。📌 **既載三軸爭議（①是否活化 ②用何手段 ③能否重複）中，第②軸的濕式分支自單一來源增為兩個來源、兩個材料體系。**
- ⭐ **強度量級對照（須標註體系，不得作優劣論據）**：本件 **~238 kPa**（SiC/藍寶石，濕式，100 °C）vs 同輪 Ge 中間層 SAB **11.2–22.3 MPa**（III-V/Si，電漿，室溫／350 °C）⇒ **相差約 50–90 倍**。⚠ 材料、量測法、界面皆不同。

## 矛盾或修正 / Contradictions / Corrections

- 無直接衝突。
- ⚠ 鄰域材料體系；**無節距、無電性、無重複性** ⇒ 不得進入混合接合技術頁之規格表，僅得入「學術前沿 / Research Frontier」。
