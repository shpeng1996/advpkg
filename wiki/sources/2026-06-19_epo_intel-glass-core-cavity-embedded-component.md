# Intel CN122249079A：玻璃核心腔體內的元件

## 核心主張 / Key Claims

1. 玻璃層具**貫穿相對兩面的開口**；**電子元件置於該開口內**。
2. 請求項同時要求**介電材料填於元件與開口側壁之間**。
3. 同一玻璃層另有**貫穿玻璃導通孔（TGV）** ⇒ 腔體與 TGV **並存於同一核心層**。

## 關鍵數據 / Key Data Points

**本件零量化值**：腔體尺寸、元件類型與厚度、介電質材料、TGV 孔徑皆未給。

## 新增知識 / New Knowledge Added

- ⭐⭐⭐ **既載「基板／核心層的腔體是一個可容納多種元件的通用結構位」取得第四個置入物**：① Shinko US20260293748A1（核心層貫穿腔體置入元件）→ ② Intel US20250112179A1（玻璃核心**凹腔**內同軸電感，供電）→ ③ Amkor US20260334253A1（有機基板腔體內**橋接晶粒**，互連）→ ④ **本件（玻璃核心**貫穿開口**內的一般電子元件）**。四例分屬三家、三種核心材料、四種功能。
- ⭐⭐⭐ **該結構位新增一個子維度：貫穿 vs 非貫穿。** ② 為 recess（單面凹入），本件為 opening between opposing surfaces（貫穿）⇒ 📌 **「腔體」此名詞須標註是否貫穿** —— 貫穿腔體同時影響兩面的佈線與應力路徑，非貫穿者不影響背面，兩者不可並列比較。加入既載「同一名詞涵蓋多個獨立驗收項」家族。
- ⭐⭐ **介電質填充入請求項** ⇒ 腔體置入物的**固定方式**首次成為排他權對象（前三件皆未述）。與既載 Shinko 案並讀，顯示**「元件如何待在腔體裡」正在成為獨立的競爭面**。
- ⭐ **Intel 在玻璃核心上的排他權密度再增**：本 wiki 既載 Intel 玻璃相關案已有 bottom-up TGV plating、partial liner、photopolymer liner、glass core hybrid panel frames、coaxial inductor in recess、裂紋抑制（本輪另一件）⇒ **Intel 的玻璃布局是全面性的，從面板成形到孔內襯層到腔體置入物。**

## 矛盾或修正 / Contradictions / Corrections

- 無矛盾。⚠ 專利為前瞻訊號，不得述為 Intel 已量產之玻璃核心形態。
- ⚠ 既載「核心層要用什麼材料」之四選一（有機／玻璃／矽／金屬）**不因本件改變**；本件改變的是**同一材料內的功能分配**。
