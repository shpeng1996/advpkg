# Samsung SEMICON Taiwan 2026：HBM5 路線圖首次詳細揭示

## 核心主張 / Key Claims
- **HBM5 目標**：2× HBM4E 整體效能；+20% 效能/W；-20% 熱阻；base die 升級至 Samsung 自研 2nm 節點（from HBM4/HBM4E 4nm）；12/16/20-Hi DRAM 堆疊；量產目標約 2028（HBM4E 之後）。
- **zHBM 目標（2029 後）**：8× HBM4E 效能；3× 效能/W；-75%～-90% 熱阻；全新架構：記憶體直接堆疊於處理器頂部（vs 傳統 HBM 並排），縮短數據傳輸距離。
- **zNAND-O（2028 年樣品）**：10× DRAM bit 密度；7× NAND 讀取頻寬和功耗效率；面向 LLM/GenAI 大容量需求。
- **CUBE 策略**：Capacity（垂直擴容）、Utilization（3D 記憶體架構最佳化，非僅堆疊層數）、Bandwidth（以垂直高速通道取代水平路徑）、Efficiency（降低每 bit 傳輸能耗）。

## 關鍵數據 / Key Data Points
| 指標 | HBM5 vs HBM4E | zHBM vs HBM4E |
|------|--------------|--------------|
| 效能 | 2× | 8× |
| 效能/W | +20% | 3× |
| 熱阻降低 | -20% | -75%～-90% |
| Base die 製程 | 2nm（Samsung in-house） | — |
| DRAM 堆疊層數 | 12/16/20-Hi | — |
| 量產時程 | ~2028 | 2029+ |

## 新增知識 / New Knowledge Added
- **HBM5 規格首次官方詳細揭示**：2nm base die + 20-Hi 堆疊上限 + 2028 量產目標——所有三項均為 wiki 首次記錄的官方數據。
- **zHBM 8× 性能目標更新**：Hot Chips 2026 揭示 +70% 功率效率（基線 HBM4e），SEMICON Taiwan 揭示 vs HBM4E 的 8× 整體效能——數量級更大，表明 zHBM 是根本架構轉變。
- **CUBE 策略框架確立**：Samsung 未來記憶體的四大軸心，尤其「Utilization — 3D 記憶體不只是堆疊層數」的論述，意味 in-package compute/PIM 方向的戰略暗示。

## 矛盾或修正 / Contradictions / Corrections
- 前次 Hot Chips zHBM 記錄為「+70% 功率效率」，本次 SEMICON 記錄為「3× 效能/W = +200%」——兩者基準不同（vs HBM4e vs HBM4E），需在 wiki 中分別標注基準。
