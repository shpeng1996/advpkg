# Samsung：堆疊晶片間採含多孔填料之非導電結構

## 核心主張 / Key Claims

第一與第二半導體晶片垂直堆疊，其間之**非導電結構包含一種含多個孔洞（pores）的填料**。申請專利範圍極為概括，僅主張「多孔填料」此一特徵。

## 關鍵數據 / Key Data Points

無。家族 ID `100903221`；IPC 含 **H10B80/00**（記憶體）、H10W70/614、H10W70/635；公開日 2026-08-20。

## 新增知識 / New Knowledge Added

**多孔填料是一個方向明確的物理取捨**：孔洞降低介電常數與彈性模數（→ 降低 CTE 失配應力），但**同時降低熱傳導率**。

## 矛盾或修正 / Contradictions / Corrections

⚠ **潛在矛盾，證據極薄，僅登錄為觀察項。**

在 HBM 堆疊中熱傳導幾乎總被優先保障。本 wiki 既有論述的方向是**熱優先**：Samsung HPB「>35% 峰值溫降」、Micron「架構圍繞熱管理」的方法論轉變、Intel 熱管理專利在堆疊頂部鋪設導熱層。本件卻暗示 Samsung 在評估一個**以熱換應力/電性**的方案，方向相反。

但證據不足以構成矛盾：
- 概括式申請案不代表產品方向
- 分類含 H10B80/00，可能瞄準 **NAND** 等非 HBM 堆疊
- 未揭露孔隙率、材料或任何熱/機械數據
