# NVIDIA $3.5B MediaTek 投資：XPU 生態系與先進封裝受益者

## 核心主張 / Key Claims

- NVIDIA 以 US$3.5B 認購 MediaTek US$3.9B ECB（新加坡交易所，2026-09-08 上市），持股稀釋僅 1.67%；Alphabet 也參與但未揭露金額——**NVIDIA 首次投資台灣上市公司**
- 合作模式從「NVIDIA GPU + MediaTek SoC」升級為「NVIDIA AI 平台 + MediaTek 客製化 XPU」；MediaTek 將提供 NVLink Fusion Chiplet + NVLink-C2C + NVHBM 作為客製加速器設計基礎
- NVIDIA 的策略邏輯：即使超大規模雲端業者以自研 XPU 取代 NVIDIA GPU，仍需依賴 NVIDIA 的互連架構、網路與機架基礎設施（「收費站」模型）
- 先進封裝直接受益者：**ASE** 與 **Sigurd Microelectronics**（與 NVIDIA、MediaTek、TSMC、Google 均有長期合作）
- 競爭格局：Broadcom 和 Marvell 仍強勁；Marvell 已獲 Google TPU 生態系定制矽合約（潛在價值 $120B）

## 新增知識 / New Knowledge Added

NVIDIA 首次直接投資台灣上市公司，且以 NVLink Fusion 平台鎖定 XPU 生態系，標誌著 NVIDIA 從「賣 GPU」轉向「賣 AI 基礎架構標準」的戰略轉型。先進封裝端：ASE 和 Sigurd 被點名為直接受益者，表示 MediaTek XPU 量產時封裝業務將進一步集中於這兩家廠商。
