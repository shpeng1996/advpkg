# SEMICONDUCTOR PACKAGE INCLUDING INTERPOSER HAVING GLASS CORE LAYER（US20260144093A1, fam 99804083）

## 核心主張 / Key Claims
1. 中介層結構＝**玻璃核心層 + 貫穿其之第一貫穿電極（TGV）**。
2. **橋結構置於第一貫穿電極「之上」**，以**橋連接凸塊**相接。
3. **橋模封層**介於橋結構與玻璃核心層之間，**並包覆橋連接凸塊的側面**。
4. 橋本身仍有**橋貫穿電極**，與橋連接凸塊垂直重疊 ⇒ 橋是有孔的，非單純佈線片。
5. 單一具名發明人（Yang Hyunjoon）。

## 新增知識 / New Knowledge Added
- ⭐⭐⭐ **「橋要埋進什麼材料裡」自 Intel 的內部分歧擴大為跨公司的分歧軸，且 Samsung 給出唯一「不埋」的答案。** 迄今六種：Intel 四種（玻璃腔體／玻璃貼片／與玻璃中介層疊成組件／有機層腔體）、珠海天成一種（矽轉接板，CN121311056A）——**全為埋入**；**Samsung 本件把橋放在玻璃核心的 TGV 之上、以模封層固定。** ➜ **新橫向論述：「埋／不埋」是比「埋進什麼」更上位的分歧軸。**
- ⭐⭐ **玻璃核心 + 橋 + 模封的組合為 Samsung 首見**，且為 `overview.md` 長期列管之「缺技術頁：Samsung X-Cube / I-Cube / LSB」再添建頁材料。
- ⭐ **「以模封而非開腔固定橋」自 ASE 單一來源擴為兩家。** 既有為 ASE CN224583751U（2026-07-31，橋接晶片組裝模封）。➜ **模封式橋接自「ASE 的個別做法」升為「兩家獨立採用的路線」**，且 Yole 的高階封裝分類已列「2.5D Bridge in Mold」為獨立類別（2026-09-26）——**本件使該分類的申請人自 1 家增至 2 家。**
- 橋含貫穿電極 ⇒ 橋不只橫向佈線，還要縱向導通 ⇒ **「橋」與「小中介層」的界線在本輪進一步模糊**（CN122270166A 亦同）。
