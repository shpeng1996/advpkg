# 上海先鋒：對位標記保護方法與面板級封裝結構（CN122476946A）

**公開號** CN122476946A｜**專利家族** 100638797｜**公開日** 2026-07-28｜**申請人** 上海先鋒科技

## 核心主張 / Key Claims

1. 在金屬對位標記上形成**兼具抗氧化與光學增強雙功能的功能保護層**。
2. 後續**加熱貼片（chip bonding）製程**中隔絕氧氣，抑制金屬標記氧化變色。
3. 同時提升標記的**光學對比度與邊緣清晰度**。
4. 效益：顯著降低**貼片搜尋失敗率**與**對位偏移修正次數**，降低報廢風險，提高面板級封裝整體良率。

## 關鍵數據 / Key Data Points

無量化數據（未給搜尋失敗率下降百分比）。

## 新增知識 / New Knowledge Added

- **一個 wiki 從未記載的面板級失效模式**：對位標記在熱製程中氧化變色 → 機器視覺搜尋失敗 → 對位偏移。這與翹曲導致的 die shift 是**兩個獨立**的對位失效來源，前者是**化學/光學**問題，後者是**機械**問題。wiki 既有的面板對位論述只涵蓋後者。
- 解法本身也值得記：**單一膜層同時做氧氣阻障與光學對比增強**，是材料側而非設備側的解，符合中國封裝供應鏈以材料切入的模式（比照 2026-09-15 收錄的 LG Chem 玻璃切單案）。
