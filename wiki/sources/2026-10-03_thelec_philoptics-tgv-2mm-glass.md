# Philoptics 取得 2 mm 玻璃基板 TGV 設備訂單

## 核心主張 / Key Claims

1. **玻璃基板的厚度正在往上走**：設備端已接到可處理 **至 2 mm** 厚玻璃的 TGV 訂單。
2. ⭐⭐⭐ **厚度是一個「兩個相反失效模式」的參數**：原文明示 **厚基板降低翹曲、但提高孔形均勻性與銅空洞防止的難度**。
3. **面板格式落在 510×515 mm**，與 Intel／Corning／LPKF 一系一致。
4. **評估階段達 0 ppm（100 萬孔無缺陷）**。
5. 量測端已進到 **高解析 2.5D 成像 AOI**。

## 關鍵數據 / Key Data Points

| 項目 | 數值 |
|------|------|
| 可處理玻璃厚度 | **至 2 mm** |

| 缺陷率 | **0 ppm / 100 萬孔** |

| 客戶／金額／孔徑／AR／產出率 | **未揭露** |

## 新增知識 / New Knowledge Added

1. ⭐⭐⭐ **「玻璃厚度」成為本 wiki 玻璃基板論述的第六個維度**（前五：熱機械、TGV 可加工性（NBO）、介電損耗、核心層功能化空間、表面佈線密度上限）。且此維度的取捨方向與其餘五者不同：**它直接對撞翹曲與孔品質兩個已分別列管的失效模式。**
2. ⭐⭐⭐ **「當一個參數同時服務兩個相反的失效模式時，最佳值必然是區間而非極值」取得第八例**，且是本 wiki 第二個上下界皆有明確物理機制者（第一為 Cu dishing：不足→空洞；過度→間隙不閉合）。本例：**薄→翹曲；厚→孔形不均＋銅空洞。**
3. **第二個獨立的玻璃通孔 0 ppm 數字**（第一為 Intel，78×77 mm 工程樣品）。⚠ 兩者口徑不同（本件為孔數基準 100 萬孔；Intel 為封裝基板基準），**不得合併、不得相互印證**。
4. **Philoptics 為本 wiki 新進之韓系玻璃加工設備商**；使玻璃加工設備端的國別分布擴為德（LPKF）、德/瑞（Manz、SCHMID）、韓（Philoptics）。
5. **AOI 的 2.5D 成像**為「TGV 需同時量頂／腰／底三個 CD」（Onto Innovation）這一要求的量測端配套首例。

## 矛盾或修正 / Contradictions / Corrections

- ⚠ **與 Ibiden「玻璃核心是翹曲的解法（~2030）」構成同軸反向的兩種主張**（見 [[sources/2026-10-03_tomshardware_abf-substrate-state-2026]]）：Ibiden 把**玻璃**當作翹曲的解；本篇把**更厚的玻璃**當作翹曲的解。兩者不矛盾（一為材料選擇、一為該材料內的厚度選擇），但顯示**翹曲是玻璃論述中跨層級反覆出現的主導失效模式**。
- ⚠ **0 ppm 的「評估階段」限定**：原文為 evaluation，非量產實績，不得與產線良率並論。
