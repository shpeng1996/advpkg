# 中央大學：超低溫 a-Si:H 濺鍍用於光子整合

## 核心主張 / Key Claims

1. HiPIMS 可在 **70 °C** 沉積高品質 a-Si:H，取得適合整合矽光子的低損耗元件。
2. 低沉積溫度**促成低熱預算的混合整合**，有助異質光子整合，為未來 CPO 實作的關鍵一步。
3. ⚠ **未做任何封裝整合實驗**；第 2 點為作者展望，非實證。

## 關鍵數據 / Key Data Points

| 指標 | 數值 |
|------|------|
| 沉積溫度 | **70 °C** |
| 折射率 n | **≈ 3.52** |
| 光學帶隙 | **≈ 1.96 eV** |
| 波導共振器 Q | **~10⁵** |
| 消光比 | **≈ 20 dB** |

## 新增知識 / New Knowledge Added

- ⭐⭐⭐ 既載橫向論述 7「熱應拆成運作熱與製程熱兩條線」的**製程熱切入點自三個增至四個**（775 µm 熱預算／退火溫度帶／鍵合頭本身／**光學層沉積溫度**），且為第一個落在光學域者。
- ⭐⭐ **70 °C 低於多數有機介電層、暫時性黏著劑與已金屬化結構的耐受上限** ➜ 光學層可在封裝流程後段才長上去，使 CPO 整合順序自「先做光學、再封裝」鬆綁為「**封裝到一半再長光學層**」，與 Lam 所列 3DIC CPO 路線（TDV+RDL+混合接合堆疊）直接相關。
