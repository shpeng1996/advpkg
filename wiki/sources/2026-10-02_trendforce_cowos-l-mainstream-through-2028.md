# TrendForce：AI 晶片封裝突破光罩極限，CoWoS-L 維持主流至 2028

> **fetch_status: partial** —— 新聞稿為報告摘要，**未給 reticle 倍數、市占百分比與絕對產能。**

## 核心主張 / Key Claims

1. **CoWoS-L 預期維持主流先進封裝方案至 2028 年。**
2. **CoWoS-S 的容量被明確定義為「2 顆 SoC/chiplet ＋ 8 顆 HBM 模組」。**
3. **CSP 自研 ASIC 的採用時程首次集中列出**，AWS 與 Microsoft 鎖定 **2027** 採用 CoWoS-L。
4. NVIDIA GPU 出貨 2026 **YoY +~30%**（⚠ 出貨「量」，非封裝面積或 CoWoS 片數）。

## 關鍵數據 / Key Data Points

| 項目 | 內容 |
|------|------|
| CoWoS-S 容量 | **2 SoC/chiplet + 8 HBM** |
| CoWoS-L 主流期 | **至 2028** |
| NVIDIA GPU 出貨 | **+~30% YoY（2026）** |
| Google | **TPU v7**，2026 年 CSP ASIC 量與成長雙居首 |
| AWS | **Trainium v3（2H26 轉換）**；CoWoS-L **2027** |
| Microsoft | **Maia 200**；CoWoS-L **2027** |
| Meta | **MTIA 400** |
| AMD | **MI400／MI450（2H26）** |
| Intel | EMIB、**EMIB-T** |

## 新增知識 / New Knowledge Added

- ⭐⭐⭐ **本 wiki 第一個對 2.5D 技術路線壽命的市場側時間判斷。** 與既有兩條論述一致指向 **2027–2028 為 CoWoS-L 與 EMIB-T 的並存競爭窗口，而非替代窗口**（ASE 吳田玉「不互斥」；Intel EMIB-T 2H27→2028→2029）。
- ⭐⭐⭐ **CoWoS-S「2 SoC + 8 HBM」可與 Samsung HBM4E「8 層中介層、75% 層數給訊號」交叉**：8 顆 HBM 的訊號佈線需求正是中介層層數緊縮的來源。
