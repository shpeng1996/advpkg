# 中國大基金三期轉向：先進封裝、設備與 AI 晶片 / China's Big Fund Phase III Pivot

## 核心主張 / Key Claims

- **Phase III 三大投資支柱**：① 先進封裝與 IP 整合（Huaxin Dingxin 主導）、② 設備與材料（Guotou Jixin 主導，最活躍）、③ AI 算力晶片
- **先進封裝代表投資**：Anhui Juhe Microelectronics（18% 股份）——中國少數能支援大量 Chiplet 生產的獨立封裝平台；Tiansui Xinyuan Technology（31.58% 股份）——汽車級視覺 ISP IP（VeriSilicon 分拆）
- **設備旗艦投資**：Tuojing Jianke（Piotech 分拆，RMB 4.5 億）——HBM 混合接合與晶片堆疊設備
- **AI 晶片**：YunSilicon（高速互連/計算網路）、TsingMicro（存算一體/端側 LLM）、Beijing Aijieko Xin（通用 AI 加速器/生成式 AI 晶片）
- **戰略邏輯轉變**：從盲目擴大產能轉為精準突破——3D IC、異質整合、設計 IP 等卡脖子環節

## 關鍵數據 / Key Data Points
