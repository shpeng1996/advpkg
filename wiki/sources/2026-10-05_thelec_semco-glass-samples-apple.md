# SEMCO 向 Apple 送玻璃基板樣品

## 核心主張 / Key Claims

1. ⭐⭐⭐ **玻璃核心基板的客戶側首次具名為 Apple**（此前先送 Broadcom）——本 wiki 此前的玻璃核心客戶討論全部停在 Intel 自用與「AI 伺服器客戶」的泛稱。
2. ⭐⭐ **送樣理由是定性的兩項**：表面平坦度高於有機材料（⇒ 更細線路）、CTE 較低（⇒ 降翹曲）。
3. ⭐⭐ **與住友化學的玻璃核心材料合資案預期 2026 H2 定案**。
4. ⚠ **量產仍為「2027 年之後」**，與本頁既載之三個互不一致說法並存。

## 關鍵數據 / Key Data Points

| 項目 | 內容 |
|------|------|
| 送樣對象 | **Apple**（自去年起）；此前 **Broadcom** |
| Apple 自研 AI 伺服器晶片 | 代號 **"Baltra"**，與 Broadcom 合作，預期 TSMC 製造 |
| 試產線 | **世宗 Sejong 廠**運行中 |
| 量產 | **2027 年之後** |
| 住友化學合資 | **2026 H2** 定案 |
| AI 封裝基板投資 | **₩6.78 兆** |

## 新增知識 / New Knowledge Added

1. ⭐⭐⭐ **「玻璃核心的需求端」第一次有具名客戶，且是行動／消費端巨頭而非伺服器 OEM。** 本 wiki 既有的玻璃核心敘事以**供給側時程分層**（設備與基材 2026–2027／專用廠 2027–2028／主流 FC-BGA 廠 ~2030）為骨架；本篇補上**需求側的第一個錨點**，且該錨點（Apple × Broadcom "Baltra"）落在 **2027 之後量產**的那一層。
2. ⭐⭐⭐ **使「Apple 無獨立實體頁」此列管空缺出現第二個觸發點**（第一為本輪 Apple 的兩件封裝專利）⇒ **本輪建立 [[entities/apple]]**。
3. ⭐⭐ **SEMCO 玻璃核心的「初期量產基地」記載須併記兩處**：本 wiki 既載為 Dongwoo Fine-Chem **平澤**廠（合資脈絡），本篇稱試產線在**世宗**廠。**兩者可能分屬試產與量產，不得合併，亦不得互相覆寫。**
4. ⭐ **₩6.78 兆的投資額與本輪 WIR 158 的「約 US$4.9B FC-BGA 擴產」量級相符**（₩6.78 兆 ≈ US$4.8–5.0B），⚠ **但兩者口徑可能不同（AI 封裝基板全部 vs FC-BGA 擴產），不得逕行認定為同一筆。**

## 矛盾或修正 / Contradictions / Corrections

- ⚠ **本篇的「2027 年之後」是 [[entities/semco]] 既載三個互不一致量產說法（2027 Q3／2028 後／2027 後由合資起）中的第三種形式**，與第三種一致。**本輪不收斂該空缺，但可記：三說之中，「2027 後由合資公司開始」已有兩個獨立來源。**
