# US20250140648A1：含深溝電容之晶圓與含背面佈線之晶圓的鍵合

⚠ **專利為前瞻訊號**；⚠ **date 2025-05-01，距今約十七個月。**

## 核心主張 / Key Claims

1. 一顆晶片含**兩層元件層**，由**兩片晶圓鍵合**而成。
2. **第一層含溝槽式元件，明示例為深溝電容**，接至第一正面互連佈線。
3. 兩層之正面互連佈線以**接合金屬塞（joined metal plugs）** 相連 —— **鍵合介面即互連介面**。
4. **第二層主動元件接至背面供電網路（BSPDN）** 與第二正面互連佈線。

## 關鍵數據 / Key Data Points

| 項目 | 內容 |
|------|------|
| 元件層數 | **兩層**（晶圓鍵合而成） |
| 下層被動元件 | **深溝電容**（trench device） |
| 層間互連 | **joined metal plugs** |
| 上層供電 | **BSPDN** |
| 分類 | H10W20/20、H10B12/*（DRAM）、H10F39/* |
| 量化值 | ⚠ **全篇無**（無電容密度、鍵合節距、對準規格） |

## 新增知識 / New Knowledge Added

- ⭐⭐ **既載「去耦電容物件化」軸（2026-10-01 立；九筆來源／五家廠商／三種載體）新增第四種載體：「被鍵合的元件晶圓層」。**
  既載 IBM 之 DTC（US20260107832A1，族 99436783）位於**晶背、混合接合之後附加**；本件之深溝電容位於**被鍵合之下層元件晶圓之內，與該層主動元件同層、接合之前即已存在**
  ⇒ **同一公司在同一軸上的第二種載體，且兩者時序相反（接合後附加 vs 接合前內建）。**
- ⭐ **「鍵合介面同時是互連介面」** 可與既載混合接合條目並讀。
