## 核心主張 / Key Claims

1. **EMIB-T ECTC 2026 完整規格確認**：25µm FLI、120×120mm、>9× reticle、12 Gb/s HBM4e、64 Gb/s UCIe。
2. **CPO V-groove 玻璃耦合器新架構**：用剛性光學玻璃耦合器取代傳統 FAU 插入 V-groove 的方式，提高可靠性、帶寬和能效，且支援**可拆卸**（detachable）。
3. **TGV 完整可靠性確認**：全銅填充 TGV 通過苛刻熱循環測試零失效；支持低錐度、混合尺寸、內嵌空腔等多種 TGV 設計。
4. **Intel + SPIL 3D SRAM Chiplet 合作**：在 fan-out embedded bridge 中進行 3D 整合 SRAM chiplet（補強其他 ECTC 來源）。

## 關鍵數據 / Key Data Points

| 規格 | 數值 |
|------|------|
| EMIB-T FLI bump pitch | 25 µm |
| EMIB-T 最大 package 尺寸 | 120 × 120 mm |
| EMIB-T 最大 reticle 數 | >9× |
| HBM4e 介面速率 | 12 Gb/s |
| UCIe 介面速率 | 64 Gb/s |
| TGV 熱循環結果 | 零失效（苛刻條件） |

## 新增知識 / New Knowledge Added

1. **V-groove 剛性玻璃耦合器**：比現有 wiki CPO 記述新增的具體機械/光學架構細節（FAU 替換方案）。
2. **TGV 內嵌空腔**：TGV 可含空腔用於 embedding devices——glass substrate 的新能力。
3. **TGV 複數尺寸混合**：同一封裝中可使用多種 TGV 尺寸，提供設計彈性。
4. 確認與 SPIL（欣興子公司）的 3D SRAM chiplet 合作。
