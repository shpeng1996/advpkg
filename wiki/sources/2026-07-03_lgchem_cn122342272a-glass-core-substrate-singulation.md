# LG Chem CN122342272A（family 99667689）

## 核心主張 / Key Claims

製程序列：
1. 於玻璃芯基板單面或雙面形成**金屬圖案**
2. 於其上形成**絕緣層**
3. **自絕緣層移除位於金屬圖案上方的部分**
4. 於絕緣層上形成**保護層**
5. **移除金屬圖案**
6. **沿金屬圖案被移除之位置切割**玻璃芯基板，形成玻璃芯基板單元

即：以犧牲性金屬圖案**預先定義一條無絕緣層覆蓋的乾淨玻璃裸露切割道**，再沿之切割。

## 新增知識 / New Knowledge Added

1. **新申請人進入 wiki 玻璃基板供應鏈地圖**：LG Chem。wiki 現有名單為 Absolics/SKC、Samsung EM（GLASEM/GlaSSEM）、Corning、DNP、Toppan、NEG、Unimicron、Shinko、LG Innotek、AGC、BOE。**LG Chem 與 LG Innotek 是集團內兩家不同公司**，前者為化學／材料，後者為基板零組件——同一集團在玻璃基板上雙線佈局，是供應鏈觀察的新資訊。

2. **切單是玻璃基板被低估的良率關卡**。wiki 既有玻璃基板論述集中在 TGV 成形（6µm @ AR>15:1）、翹曲、CTE 匹配、TGV 電性（220 GHz @ 0.3dB）。本案指出的是製程末端：直接切穿玻璃 + 絕緣／介電疊層會造成崩邊與微裂紋。這與 wiki 已記錄的「邊緣應力塗層後 95 MPa → 49 MPa」屬同一問題族——**玻璃的良率瓶頸在邊緣，不在 TGV 本身**。兩條獨立證據指向同一結論，可在技術頁形成一個明確論點。

3. **IPC 分類的供應鏈意涵**：本案落在 C03C（玻璃）與 H05K（印刷電路板），**完全不在 H01L／H10（半導體）**。這反映玻璃基板的 IP 目前仍主要由材料與 PCB 體系持有，而非半導體體系——對「玻璃基板由誰主導、誰有議價權」的供應鏈論述是一項可引用的結構性觀察。
