# [專利訊號] Adeia：有機 + 無機雙介電層的低溫接合面

## 核心主張 / Key Claims

1. 於基板上形成金屬特徵；以**有機介電層覆蓋金屬特徵側壁**；再於其上形成**無機介電材料**；最後對三者一併 CMP 平坦化作為混合接合面。
2. 同一發明人群於 **2026 年內公開三個 family-id** 的同概念案（98319206 / 99060534 / 99226182），為圍籬式布局。

⚠ 三件摘要**均未揭露任何量化數值**（無溫度、無粗糙度、無 pitch）。

## 新增知識 / New Knowledge Added

1. ⭐⭐ **結清 2026-09-19 列管空缺「PHB（聚合物／有機介電混合接合）的第二個來源」，且來源強度超出原本設定的門檻。** 該空缺原文設定：「若出現第二家（材料商或 IDM），可自『平行路線』升格為『第五條低溫路線』」。本件申請人為 **Adeia**——混合接合的核心專利持有者（正對 AMD 提起訴訟者）。合計同輪 JCET CN122421815A 亦採有機介電層 ➜ **一季內三個獨立申請人**：材料商（Toray）、IP 持有者（Adeia）、OSAT（JCET）。**有機介電混合接合正式升格為技術路線。**
2. ⭐ **這是與既有四條低溫路線不同類的一條。** 既有四條（微波退火、Pd 表面合金化、表面活化、Adeia 局部加熱感受體）都在**降低達成 Cu-Cu 接合所需的熱預算**；本件改變的是**介電層材料本身**。➜ 低溫路線應重新分為兩類：**降低所需溫度** vs **更換需要溫度的那一層**。
3. **結構同時對應兩條既有論述**：（a）有機層貼金屬側壁 = 在 Cu／介電 CTE 失配應力最大處插入順應層；（b）最終 CMP 需同時研磨**三種材料**。

## 矛盾或修正 / Contradictions / Corrections

- ⚠ **本件與本 wiki 2026-09-19 的核心結論之間存在一個未解的張力，列為新空缺**：若「CMP 是限制鏈第一層」成立，則要求 CMP 同時平坦化無機介電、有機介電與 Cu **三種材料**（選擇比控制比雙材料更難）**實際上加重了限制層的負擔**。本件是繞過限制還是加劇限制，摘要無法判定。
- 專利為前瞻訊號，非已出貨能力。Adeia 於 2026 上半年公開之布局**不代表任何產品採用**。
