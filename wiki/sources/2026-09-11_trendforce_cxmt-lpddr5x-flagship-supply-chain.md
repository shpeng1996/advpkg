# CXMT LPDDR5X 10.667Gbps 進入旗艦供應鏈

## 核心主張 / Key Claims

- Samsung + CXMT 雙供應商供應努比亞 NaviX Ultra（中興+字節跳動聯合開發）旗艦手機 LPDDR5X
- CXMT LPDDR5X 最高速度從 2025-05 的 8.533-9.6Gbps 提升至 2026-09 的 **10.667Gbps**，已與三星/SK hynix 頂級產品齊平
- 中國旗艦手機首次採用韓中雙供應商記憶體策略
- CXMT LPDDR6（12,800Mbps）同期已量產並進入小米 18 Fold

## 關鍵數據 / Key Data Points

| 指標 | 數據 |
|------|------|
| CXMT LPDDR5X 速度（2025-05 量產初期） | 8.533–9.6 Gbps |
| CXMT LPDDR5X 速度（2026-09） | 10.667 Gbps |
| Samsung/SK hynix 頂級 LPDDR5X | 10.7 Gbps-class |
| CXMT LPDDR6 速度 | 12,800 Mbps（12.8 Gbps） |
| LPDDR6 vs LPDDR5X BW 提升 | +60% |
| LPDDR6 vs LPDDR5X 功耗 | -20% |

## 新增知識 / New Knowledge Added

- CXMT LPDDR5X 速度量化追蹤（從 2025-05 至 2026-09 的進步幅度）
- 中國旗艦手機供應鏈記憶體雙軌化（韓+中），標誌 CXMT 正式打入旗艦市場
