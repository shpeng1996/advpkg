# TSMC 高雄白埔先進封裝聚落

## 核心主張 / Key Claims

1. TSMC 於高雄白埔工業園區設立先進封裝聚落，**用途為設備與材料的測試驗證、製程研發、人才培訓與供應鏈連結**，而非量產。
2. 設施採**模組化、可重構**設計。
3. 與經濟部、高雄市政府合作。

## 關鍵數據 / Key Data Points

| 項目 | 數值 |
|------|------|
| 面積 | **3 公頃**，兩棟建築 |
| 驗證效率提升目標 | **25–50%** |
| CoWoS 產能 CAGR（至 2027） | **>80%** |
| 成長延續 | 至 **2029** |

（原文未揭露投資金額。）

## 新增知識 / New Knowledge Added

1. **「驗證效率提升 25–50%」是罕見的量化目標，且對象是驗證而非產能。** TSMC 以 3 公頃專屬園區加速**設備與材料驗證**，說明在 CoWoS 產能 CAGR >80% 的擴張速率下，**瓶頸已部分轉移到供應鏈驗證的前置時間**——這與本日三軌收錄共同指向的「測試／驗證左移」主線在**產業組織層級**上互相印證。
2. **CoWoS CAGR >80% 至 2027**，為既有 CoWoS 產能數列補上官方口徑成長率。
3. 「模組化、可重構」廠房設計，呼應 SemiEng 所述「封裝架構每季到每半年改一次」——**廠房設計本身在對沖架構不穩定性**。
