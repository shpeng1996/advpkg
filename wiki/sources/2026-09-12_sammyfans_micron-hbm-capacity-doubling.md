# Micron HBM 產能倍增

## 核心主張 / Key Claims

1. Micron 計畫 **2026 年底前增加最多 60,000 HBM wafer starts/月**，總量達約 **100,000 wpm**，較前一年的 40–50K **翻倍**。
2. 36 GB 12-high HBM4 已量產供 NVIDIA Vera Rubin，單堆疊頻寬 **>2.8 TB/s**。
3. 12-high HBM4 年底可佔 Micron HBM 產出 **最高 50%**（年初為 20–30%）。
4. 即使如此，Samsung 與 SK hynix 仍保有顯著產能優勢。

## 關鍵數據 / Key Data Points

| 項目 | 數值 |
|------|------|
| 新增產能 | **+60,000 HBM wspm**（2026 年底前） |
| 擴張後總量 | **~100,000 wspm** |
| 前一年基準 | 40,000–50,000 wspm |
| HBM4 12-high 頻寬 | **>2.8 TB/s** / 堆疊 |
| 12-high 佔比 | 20–30%（年初）→ **最高 50%**（年底） |

## 新增知識 / New Knowledge Added

1. **HBM 產能首次可與封裝產能做同單位對照。** Micron 單家年底 ~100K HBM wpm，對照 CoWoS 全球 120–140K wpm（同輪 Benzinga 來源）。兩者計量對象不同（HBM 晶圓 vs 封裝載板晶圓），但數量級相當——顯示**記憶體端與封裝端的擴張節奏已大致同步**，過去「HBM 供應充足但 CoWoS 卡住」的單邊瓶頸敘事需要修正為雙邊同時擴張。
2. **2.8 TB/s / 堆疊** 補上 wiki `hbm4.md` 中 Micron 側缺失的一手頻寬數字（既有記錄為 >11 Gbps pin speed）。
