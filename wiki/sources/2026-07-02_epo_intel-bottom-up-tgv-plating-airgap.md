# 專利訊號：Intel 自底部 TGV 鍍膜與刻意保留的空氣間隙

## 核心主張 / Key Claims

1. 製程從「側壁鍍種子層後填充」改為**自 via 底部單向長晶**，**不需側壁種子層**。
2. 以圖案化黏著層預先露出金屬箔，作為底部種子。
3. 結果結構**在鍍成的銅與玻璃之間保留空氣間隙（airgap）**。
4. 發明人達 **22 名**，屬平台級布局而非單點改良。

## 新增知識 / New Knowledge Added

1. ⭐ **空氣間隙的用途應理解為應力解耦，而非電性隔離。** Cu 與玻璃的 CTE 差異在熱循環時撕裂界面，是玻璃基板最受質疑的可靠度環節（wiki `glass-substrate.md`「可靠性挑戰」已載）。若刻意在銅與玻璃之間留空隙，銅的熱膨脹便不再直接推擠玻璃。這是一個**用幾何換材料匹配**的解法。
2. **22 名發明人**的規模本身是訊號：Intel 把 TGV 金屬化當作平台級工程問題投入，而非實驗室選項。

## 矛盾或修正 / Contradictions / Corrections
- ⚠ 專利為前瞻訊號。Intel 於 2026-07 公開之專利顯示其製程探索方向，**不得視為已量產能力**；wiki 既有「Intel 玻璃基板 HVM 候選廠 Rio Rancho」等記載不因本案改動。
- ⚠ 空氣間隙在高頻與熱傳導上可能有反效果（空氣是熱絕緣體），專利文本未討論此代價。列為未解問題。
