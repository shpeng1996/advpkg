# SK hynix to tap Intel foundry for next-gen HBM base die（The Herald Business, 2026-08-31）

## 核心主張 / Key Claims

1. ⭐⭐⭐ **base die 的成本結構首次量化：HBM4 之 TSMC base die 成本為 core die 的 3–4 倍**（業界消息來源）。core die 為 SK hynix 自家 **1b（10 奈米級）**；base die 為 **TSMC 12 奈米級**。
2. ⭐⭐ SK hynix **據報考慮自 HBM4E（第七代）起改用 Intel Foundry 製作 base die**；Intel 節點未揭露，無官方確認。
3. ⭐⭐⭐ **可歸因之公開陳述**：Hot Chips 上，SK hynix America 封裝工程副總 **Lee Jae-sik** 表示公司**正在比較 TSMC 的 CoWoS-S 與 CoWoS-L 以及 Intel 的 EMIB**。
4. **HBM3E base die 為 SK hynix 自製** ⇒ base die 的代工歸屬在一個世代內自「自製」轉為「外購」。
5. 分散供應的四個理由（後兩項為分析師觀點）：降低 TSMC 集中度、建立多供應商結構、取得議價槓桿、**支援 custom HBM（base die 依個別 AI 客戶客製）**。
6. SK hynix 於 **Computex 2026（2026-06）**展示 **HBM4E 12 層 48GB** 樣品。

## 新增知識 / New Knowledge Added

1. ⭐⭐⭐ **既載知識空缺「HBM base die 供應鏈」首次取得一個成本數字，而該數字改變了問題的形狀。** 既載論述把 base die 的代工歸屬當作**技術能力問題**（誰能做先進邏輯）；**3–4 倍成本比**把它變成**成本結構問題**：一個 HBM 堆疊裡，**最貴的單一晶粒不是任何一顆記憶體，而是那顆邏輯底座**。⇒ 📌 **這解釋了為何「分散 base die 供應」在 2026 年同時出現在 SK hynix（考慮 Intel）與 Samsung（開放 custom base die 給 TSMC，既載）兩家身上——動機是成本而非產能。**
2. ⭐⭐⭐ **「CoWoS-S / CoWoS-L vs EMIB」被一家記憶體廠放在同一張比較表上，且出自其封裝工程副總之口。** 既載論述把 CoWoS 與 EMIB 當作**代工廠之間的競爭**（TSMC vs Intel 爭取加速器客戶）；本件顯示**記憶體廠自己也在選 2.5D 平台** ⇒ 📌 **2.5D 平台的採購決策者此後應記為至少兩類：加速器設計者與記憶體供應者。**
3. ⭐⭐ **base die 代工歸屬的世代軌跡成形**：HBM3E 自製 → HBM4 外購 TSMC 12nm → HBM4E 候選 Intel。與既載 Samsung（HBM4 自家 4nm、3D 封裝自理）形成**兩條相反策略**：SK hynix 外部化、Samsung 內部化。
4. ⚠ 「Intel 關係可能擴及先進封裝」為本文明示之推測，**不記為訊號**。
