# JP2026501395A：CEA + SET 的 D2W 直接混合接合方法

⚠⚠ **優先權日 2022-12-28 / 2023-12-22；本件僅為日本國家階段公開。依本 wiki 規範，不可讀為 2026 年的新想法。**

## 核心主張 / Key Claims
提供含第一銅墊與第一氧化矽層之**晶粒**、含第二銅墊與第二氧化矽層之**晶圓**，對準銅墊後將晶粒接合面朝向晶圓接收區域。⚠ OPS 回傳之日文摘要於此處截斷，後續步驟未取得；發明人欄為空。

## 關鍵數據 / Key Data Points
⚠ **無 pitch、對準精度、良率或溫度數值可取得。** 本件的價值在申請人組合與時序。

## 新增知識 / New Knowledge Added
1. ⭐⭐ **申請人組合本身是訊號**：**CEA**（CEA-Leti 母體）＋ **SET Corporation**（法國高精度晶粒貼合機商）。本 wiki 已收錄 CEA-Leti 的 **ECTC 2026 D2W 1 µm** 發表；本件顯示該機構**早在 2022 年底即與設備商共同申請 D2W 直接混合接合的製程方法專利**。➜ ⭐ **本 wiki 首次能對同一機構量到「排他權布局 → 學術發表」的間隔：約三到四年。** 這對解讀所有 ECTC／IEDM 發表有方法論意涵：**論文出現時，對應的 IP 往往已布局數年，因此論文是落後指標而非領先指標。**
2. ⭐ **D2W 混合接合的設備側 IP 不只有 Besi／ASMPT／EVG 三強**，法國 SET 亦在列。補強 2026-09-21 記錄的「EV Group 2026 年公開案密集」觀察。➜ SET 列為實體頁待建候選（優先序低於 Hanmi）。
