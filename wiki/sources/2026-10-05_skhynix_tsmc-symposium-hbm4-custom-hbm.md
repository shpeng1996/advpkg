# SK hynix at TSMC Technology Symposium 2026（一手來源）

## 核心主張 / Key Claims

1. ⭐⭐⭐ **「HBM4 的 base die 採 TSMC 先進邏輯製程」由 SK hynix 自己以一手來源確認**——本 wiki 此前此一事實多倚二手報導。
2. ⭐⭐⭐ **HBM4 規格由記憶體廠一手表述為 16-layer / 48 GB**，與本 wiki 既載之「16-Hi 48 GB 客戶驗證中」一致。
3. ⭐⭐ **自標準 HBM 走向 custom HBM** 的承諾來自一手。
4. ⭐⭐ **後續方案兩條：HBF（logic-based NAND）與 3D Stacked DRAM on Logic。**
5. ⭐ 所引 TSMC 封裝技術三件：CoWoS（2.5D 併排）、InFO（降厚度）、**SoIC（3D 垂直堆疊，採混合接合）**。

## 關鍵數據 / Key Data Points

| 項目 | 數值 |
|------|------|
| HBM3E | 12-layer，已搭載 NVIDIA **GB300** |
| **HBM4** | **16-layer、48 GB、base die = TSMC 先進邏輯** |
| 3DS RDIMM | **256 GB** |
| MRDIMM | **128 GB** |
| RDIMM | **64 GB**（1c nm） |
| SOCAMM2 | **192 GB**（1c nm） |

## 新增知識 / New Knowledge Added

1. ⭐⭐⭐ **對列管空缺「HBM base die 供應鏈」給出一手錨點**：**記憶體廠承認 base die 在代工廠**，且與其**「記憶體與邏輯整合」**的願景表述並置（CDO 安現語）。➜ 這使本 wiki 2026-10-04 所記之論述 16（「base die 的製程外移，正在把『誰負責堆疊』也一起鬆動」）取得**來自記憶體廠自身的佐證**，而非僅由 TSMC×Winbond 的反向案例推得。
2. ⭐⭐⭐ **本篇與本輪 TSMC×Winbond 一案並讀，可見同一家代工廠在 HBM 鏈上同時扮演兩種角色**：對 SK hynix 是 **base die 供應者**（記憶體廠自行堆疊）；對 Winbond 是 **堆疊與封裝執行者**（記憶體廠只供晶圓）。➜ ⭐⭐⭐ **新論述：「代工廠在記憶體鏈中的位置不是單一的，而是依客戶議價能力而變。」**
3. ⭐⭐ **HBF 的定性「logic-based NAND」是本 wiki 既有 [[technologies/hbf]] 頁的一手補強。**
4. ⭐⭐ **「3D Stacked DRAM on Logic」與本輪 Winbond 案的「DRAM 在下、SoC 在上」方向相反**（前者 DRAM 疊於 SoC 上）⇒ **WoW 的上下順序本身是一個設計變數，本 wiki 首次有兩個相反實例可對照。**
