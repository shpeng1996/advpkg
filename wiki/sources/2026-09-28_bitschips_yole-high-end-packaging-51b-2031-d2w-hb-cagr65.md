# AI drives high-end packaging market past $51B by 2031（Yole）

## 核心主張 / Key Claims
1. 高階封裝 **2031 年 >$51B，CAGR 27%**；件數 +33%、晶圓需求 +30% ➜ **金額成長遠快於實體量，代表單價上升是主要驅動力。**
2. **依技術別 CAGR 首次分項揭露**，其中 **D2W 混合接合約 65%** 為全場最高。
3. 電信與基礎設施占 2031 年營收 **70%（>$36B）**；車用成長最快（CAGR 36%）。
4. **前六大（Intel、TSMC、YMTC、SK hynix、Samsung、Micron）約占 2025 年營收 97%。**

## 關鍵數據 / Key Data Points

| 技術區隔 | CAGR（2025–2031） |
|----------|------------------|
| **D2W 混合接合** | **約 65%** |
| W2W 混合接合 | 更快，但基期更小 |
| Mold interposer（CoWoS-L） | 28.1% |
| 3D NAND（混合接合） | 22.2% |
| CPO | 2025 近乎零 → 2031 數億美元 |
| 整體高階封裝 | 27% |
| 車用（終端市場） | 36% |

## 新增知識 / New Knowledge Added
- ⭐⭐⭐ **混合接合首次有依情境（D2W / W2W / 3D NAND）分項的市場成長率。** 既有記載只有設備面（Yole：TCB + HB 設備 2030 $1.3B）與技術面（節距、良率、對準）。➜ **D2W 65% vs 3D NAND 22.2% 的三倍落差，量化了「3D NAND 是混合接合的存量市場、D2W 邏輯/記憶體堆疊是增量市場」。**
- ⭐⭐⭐ **「件數 +33%、晶圓 +30%、金額 CAGR 27%（六年約 4.2×）」三者的落差本身是結論**：高階封裝的成長幾乎全來自**每件價值提升**（更大封裝、更多 HBM、更多光罩倍數），而非件數。
- ⭐⭐ **前六大占 97%**：高階封裝營收主要記在 IDM／代工／記憶體廠帳上，**OSAT 在此定義下幾乎不入列** ➜ 直接回應 overview 之「OSAT 競爭格局」缺概念頁：該頁必須先界定「高階封裝營收如何歸屬」。

## 矛盾或修正 / Contradictions / Corrections
- ⚠⚠ **CPO「2031 數億美元」看似遠低於 2026-07 TrendForce「2027–2028 放量」的語氣**。兩者統計口徑（CPO 封裝產值 vs CPO 交換器系統產值）未確認，**不得相除或排序**。
- ⚠ 與 wiki 既有「Yole：先進封裝 2024 >$40B → 2030 >$80B（CAGR 9.5%）」並存：**9.5% vs 27% 的落差來自「全部先進封裝」與「高階封裝」的定義差**，須在引用時標明採用哪一組。
