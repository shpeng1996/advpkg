# Shinko Beats Micron for Japan Display Factory: Glass Substrate AI Push Begins

**Tech Times｜2026-09-30**

## 核心主張 / Key Claims

1. Shinko 取得 **JDI 茂原工廠**（千葉縣茂原市），定位為「**先進半導體封裝的新核心工廠**」，用於**AI 晶片封裝之玻璃芯基板**。
2. **交割 2027 年 3 月底；投產 FY2028。**
3. 競標者含 **Micron Technology**、資料中心業者及至少一家其他半導體／資料中心標的方。
4. 廠區東側 **140,000 m² 歸 Shinko**；西側 **232,000 m² 轉予 FICT Co., Ltd.**
5. Shinko 之 **22 層玻璃基板＝兩面各 11 層銅佈線**。

## 關鍵數據 / Key Data Points

| 項目 | 數值 |
|------|------|
| 總用地 | **約 373,000 m²**（92 英畝） |
| 無塵室 | **約 179,000 m²** |
| **可用電力** | **> 100 MW** |
| 收購價 | **未揭露**；JDI 認列**約 514 億日圓**特別利益 |
| 交割／投產 | **2027-03 底／FY2028** |

## 新增知識 / New Knowledge Added

1. ⭐⭐⭐ **玻璃芯從研發轉入「建廠＋電力」階段的第一個具體場址數字。**
   **>100 MW 與 179,000 m² 無塵室**是本 wiki 首見的玻璃基板產線基礎設施量級。
   ➜ 既有玻璃基板記載全在材料、TGV 製程、良率（玻璃面板 70–85% vs 有機 >90%）層級，**無任何產能或基礎設施數字**。
2. ⭐⭐⭐ **「22 層＝兩面各 11 層」首次拆解。**
   2026-08-18 TrendForce（已收錄）僅記「22 層」，未知單面或雙面計數。
   ➜ 與本輪 Shinko US20260293748A1（核心貫穿腔體置入元件）同屬**核心層功能化 + 雙面對稱增層**路線。
   ➜ ⚠ 兩面各 11 層的對稱結構對**翹曲**的含意未見討論，列為空缺。
3. ⭐⭐⭐ **邊界外擴第五型態：面板廠的廠房與電力資產進入先進封裝。**
   前四型態（2026-09-29／30 記載）：①玻璃／陶瓷製造業者以自身製程進入基板層 ②載板業者 ③IDM 向載板業取用製程（Pd 活化＋無電鍍）④玻璃廠進入基板層。
   本件為**面板廠的實體資產（廠房、無塵室、電力、方形基板產線設備）轉移**。
   ➜ **新論述（⭐⭐⭐）**：「**玻璃基板偏好大面積方形基板，與面板廠的廠房與設備同型，故面板產業的衰退資產成為先進封裝的現成基礎設施。這是一次結構性的資產轉移，而非單純的財務交易。**」
   ➜ 與 SHIELD USA（本輪，模封 fan-out、大面積方形）形成**同一方向、不同材料**的對照。
4. ⭐⭐ **FY2028 投產 ⇒ 2027 年內玻璃芯基板不會有來自此廠的量產供給。**
   與 Ibiden 之 FY2027（有機 ABF）形成**日系兩大基板廠相差一年、材料路線相異的兩種賭法**（見 `2026-10-01_ibiden-500bn-capex`）。
5. ⭐⭐ **Micron 競標同一座面板廠，動機不明，列為⭐⭐空缺。**
   記憶體廠爭取面板廠房的可能用途：HBM 後段？玻璃中介層？純廠房／電力？
   ➜ 若為玻璃相關，則**記憶體廠也在評估玻璃路線**，這是本 wiki 全新的方向。
