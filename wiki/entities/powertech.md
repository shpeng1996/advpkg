# Powertech Technology Inc.（力成科技）

**類型 / Type**：OSAT（委外封裝測試）
**總部 / HQ**：台灣，竹北（Zhubei, Taiwan）
**關鍵人物 / Key People**：Chairman D.K. Tsai（蔡篤恭）

## 核心技術 / Core Technologies

- **PiFO（Panel-level integrated Fan-Out）**：自研面板級扇出封裝，510×515mm 方形面板，矽橋接+RDL+ABF 基板
- **EFB（Elevated Fanout Bridge）**：TSMC CoWoS-L / Intel EMIB 的面板型替代方案（AMD 確認為業界首款面板型 2.5D EFB）
- 傳統記憶體封裝測試：HBM、DRAM、NAND Flash（Micron、Kioxia、SanDisk 主要封測合作廠）

## 近期動態 / Recent Developments

- **2026-08-31（⭐最新）**：宣布 **NT$70 億（~US$2.2 億）** FOPLP 投資；PiFO 目標 **2027 年中量產**，宣稱全球首座 AI 晶片面板級封裝設施；AMD 與 Broadcom 已預訂 2027 年全部產能，需求確保至 2030 年。
- **2026-08-31（⭐最新）**：與 Broadcom 合資新加坡 FOPLP 廠（加成式細線 RDL），預計 **2028 年**投產。
- **2026-08-31（⭐最新）**：CPO（共封裝光學）整合 ASIC+光學元件目標 **2027 年量產**；光引擎 2026 年底小量出貨。
- **2026-07-28**：進入 AMD AI GPU 供應鏈（2Q26 確認）；Powertech + Broadcom 新加坡 JV 加成式 RDL 建立。
- **2026-05-26**：AMD COMPUTEX 2026 確認 Powertech 完成業界首款**面板型 2.5D EFB 互連認證**。
- **2026-05**：FOPLP 試驗良率達 ~**95%**；CapEx 上調 NT$40B → NT$50B。

## PiFO 技術規格 / PiFO Technology Specs

| 指標 | 數值 |
|------|------|
| 面板尺寸 | 510 × 515 mm 方形 |
| 每片面板產出 | 45–90 封裝單元（依尺寸） |
| 目標應用 | AI ASIC + HBM 整合封裝；CPO |
| 量產時間 | 2027 年中 |
| 投資金額 | NT$70B（~US$2.2B） |
| 2026 產能 | 1,000 片/月 |
| 2028 產能 | 5,000 片/月 |
| 需求鎖定期 | 至 2030 年 |

**PiFO 技術差異化**：
- vs. TSMC CoWoS：方形面板替代圓形晶圓，面積利用率更高
- vs. Intel EMIB：無需基板空腔嵌入，製程彈性更大
- 底部 RDL → 矽橋接+微凸塊（ASIC+HBM）→ 上方 RDL → ABF 基板接合
